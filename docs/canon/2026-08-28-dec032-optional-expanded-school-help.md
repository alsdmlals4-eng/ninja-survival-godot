## 1. 결정

첫 `0:00–0:30` 전투에 강제 마이크로 안내, 자동 튜토리얼 카드, 행동 유도 마커를 추가하지 않는다.

대신 플레이어가 **원할 때만** 현재 선택한 유파의 확장된 한국어 도움말을 확인할 수 있게 한다. 현재의 전투 HUD `기능 도움말` → 단일 `HelpDialog` 경로를 재사용하는 것이 기본이다. 선택 전 별도 도움말 진입점은 현재 구현 사실이 아니며, 이 결정만으로 추가하지 않는다.

## 2. 도움말이 설명해야 할 것

각 유파 도움말은 실제로 구현되었거나 같은 승인 구현계약에서 실제로 구현할 행동만 다음 순서로 명확히 설명한다.

1. **위험 처리 방식:** 이 유파가 무엇을 안전하게 만들거나 우선 제거하는가.
2. **플레이어가 볼 것:** 적의 거리·군집·결계·표식 등 판단에 필요한 화면 정보.
3. **플레이어가 시도할 것:** 이동·위치 조정으로 만들 수 있는 유리한 상황. 자동전투의 조준/시전 소유권은 바꾸지 않는다.
4. **성공 신호와 다음 목표:** 아이콘, 결계, 반응, 자원/궁극기 준비 등 관찰 가능한 결과와 다음 행동.

문구는 현재 런타임의 사실을 넘어서 미래 패턴, 자동 보상, 숨은 수치, 확정되지 않은 밸런스 값을 약속해서는 안 된다. 천술류는 DEC-027/028의 공간 반응을 실제 구현한 뒤에만 그 행동과 청색 준비·호박/주황 결과를 설명한다.

## 3. UI 및 시각 경계

- 상태는 여전히 compact icon-first이며, 지속적인 텍스트 상태 배지를 다시 도입하지 않는다.
- 도움말의 서술은 선택형 설명/접근성 경로다. 전장 위 상태 표현이나 별도 runtime asset이 아니다.
- `SchoolSelectionUI`는 학교 선택의 단일 owner로 남고, `HUD`는 intent만 낸다. 도움말을 열거나 닫아도 학교, Route, Fate, Backpack, 전투 modifier, 보상 상태를 변경하지 않는다.
- T16의 포커스 복귀와 선택 입력 차단 경계를 보존한다. 전투를 강제로 시작·중단·재선택시키는 tutorial flow는 만들지 않는다.

## 4. 검증 경계

선택형 도움말은 첫 30초 무보조 이해의 대체물이 아니다.

- Human Slice는 먼저 도움말을 열지 않은 상태에서 유파의 위험 처리 방식과 결과를 어떻게 해석하는지 관찰한다.
- 이후 필요할 때 도움말을 열어, 문구가 실제 행동·정보·결과를 정확히 연결하는지 확인한다.
- 도움말을 읽은 뒤에만 이해가 성립하면, 무보조 첫인상은 `PARTIAL`로 기록하며 `PASS`로 승격하지 않는다.
- Human Usability, Player Experience, live render, touch/device/export evidence는 계속 `NOT_RUN`이다.

## 5. 범위와 제외

이 결정은 설명 방식만 확정한다. 네 유파 lifecycle, Cheonsul 공간 반응, Trace/Workbench, GOLD 재도전, UI 구현, 새 Scene/asset, 수치 튜닝, Human validation 실행을 구현 완료로 주장하지 않는다.

## 6. 재검토 조건

- 확장 도움말이 실제 runtime 또는 승인된 구현계약과 어긋난다.
- 설명을 읽어도 플레이어가 무엇을 보고 이동해야 하는지 말하지 못한다.
- 선택형 설명이 지속 상태 텍스트 또는 강제 tutorial로 변질된다.
- Human Slice에서 무보조 첫 30초 가독성이 반복적으로 실패한다. 이 경우 강제 안내를 다시 제안할 수 있으나, 별도 제품 결정을 거친다.

## 7. 적대적 검토 — 전체 범위 5회

1. **강제성:** 시작 직후의 행동→결과 안내를 제외했으며, 사용자가 명시적으로 도움말을 열 때만 자세한 설명을 본다.
2. **진실성:** 현행 `SCHOOL_HELP`/각 Runtime 사실과 같은 계약의 실제 구현만 설명하게 해 미래 기능을 이미지·문구로 발명하지 못하게 했다.
3. **시각 일관성:** 상태 아이콘 원칙을 지키며, 긴 설명이 전장 위 지속 HUD가 되지 않게 했다.
4. **소유권:** 선택/Route/Fate/Backpack/전투 수치를 UI 텍스트로 이동시키지 않았고 T16의 한 Dialog owner를 보존했다.
5. **증거:** 선택형 안내가 도움 될 수 있어도, 무보조 첫 30초 이해나 Human/Player PASS를 주장하지 않도록 검증을 분리했다.

## 8. Base 승격 판정

`NO_BASE_PROMOTION`: 유파별 실제 행동과 기존 Godot 도움말 소유권에 묶인 프로젝트 고유 결정이다. “선택형 설명은 무보조 UX 검증을 대체하지 않는다”는 공용 원칙은 현재 Base owner가 이미 소유하므로 복제·승격하지 않는다.
