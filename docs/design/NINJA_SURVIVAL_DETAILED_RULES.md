## 1. 장르·세계관·핵심 재미

### 2026-09-20 승인된 성장 분리 — R-CAMP

최신 사용자는 비파괴 확률 강화 권장안과 직접 플레이 가능한 전체 여정 구현,
상세 데이터 판단을 위임했다. 기존 R-TRACE의 숫자 단계+1은 새 흔적에는 적용하지 않는다.
장비 인스턴스의 `imbuements`는 유파 효과, 기존 `upgrade_rank_by_instance`는 수치
단계(0..4)다. 예전 숫자 강화 저장은 그대로 보존하고 유파 효과를 소급 발급하지 않는다.
부여 기록이 없는 옛 장비 스냅샷은 빈 부여로 읽는다. 실제 사용자 파일의 강제 재작성은 없다.

- 유파 강화는 실패 없이 선택 장비에 유파 효과1개. 흔적은 전장당1개이고 유파는
  런당 한 번만 부여한다. 같은 장비에 다른 유파 효과는 함께 존재할 수 있다.
  다른 장비 교체/판매로 효과가 이전되지 않는다. 시작 유파의 책/해금은 유지한다.
- 엽전 강화 시험값: +1/+2/+3/+4 비용20/35/55/80, 성공80/65/50/35%.
  실패는 비용만 소모하고 단계/부여 보존, 성공은 기존 무기+15%/닌자복+3%p 규칙.
  처음에는 숨은 확률 보정 없이 화면의 표시 확률과 실제 확률을 일치시킨다.
  이 값은 초기 플레이 조정값이지 벤치마크에서 입증된 정답이 아니다.
- 유파 효과의 장비별 시험값은 구조화 `equipment_growth_catalog.gd`가 소유한다.
  귀인 무기 흡혈(근접4%,투사3%,원타 피해만,최대2HP/0.25초), 의복 재생(1HP/2초);
  흑영 회피(근접/투사4%p,의복8%p; 기존 전체40% 상한);
  천술 무기 속성 추가(20%,원타25% 추가,인술·추가타 재발동 없음), 의복 원소 방호(피해감소5%p);
  봉마 무기 적중 보호막(4초당3HP), 의복 자동 보호막(8초당8HP,중첩 누적 없음).
  무기 효과는 그 무기의 사건에서만 발동한다. 의복의 방어 효과는 착용 중만 적용한다.
- 인법은 해금 유파만 구매 가능, 가방 밖 비활성. 가방 강화는 기존 가방 구매/확장.
  소모품은 회복약(휴식 즉시25HP,15엽전)과 비상약(HP25% 이하 자동25HP,25엽전,
  최대1개 보관)부터 연결한다. 휴식 회복과 구매 효과는 저장된 HP를 기준으로 한 번만 적용.
  최초 휴식 회복은 최대HP25% + 기존 운명/장비 휴식 회복 비율에 회복 효율을 적용한다.
  저장된 HP 상한을 넘지 않으며, 보상 후보와 같은 진입 거래로 기록한다. 실플레이 균형은 미검증.
  인법/장비는 준비 화면의 별도 목록에서 해금·미소유 품목을 구매하고, 기존 공간 보조
  3개 제안/가방 후보는 그대로 유지한다. 구매 장비는 자동 장착하지 않으며 인법은
  버퍼로 받아 배치·출전 후에만 발동한다. 미해금 유파 인법은 판매하지 않는다.
  부여의 공격 효과는 기본무기의 시전당 첫 실제 명중만 사용한다(오의/인법/추가타 제외).
  흡혈 소수점은 전투 중 누적하되 효율 보너스를 적용한 실제 회복도2HP/0.25초 상한이며,
  장비 교체/새 출전 시 임시 잔여값과 부여 보호막을 해제한다. 천술 추가타는 재귀 발동하지 않는다.
  전투 시간을 정지한 준비 단계에서 구매하며 인법/가방과 같은 기존 엽전 경제를 사용한다.
- 비용/결과/보유품은 한 저장 거래다. 클릭 반복·저장 실패·재개로 결과 재추첨이나
  중복 차감 없음. 결과 확정 전 애니메이션은 소비/효과를 소유하지 않는다.

반증: 흡수/강화 한쪽이 항상 정답, 전투와 무관한 노가다 클릭, 회복 폭증,

**공간 빌드형 액션 서바이버 로그라이트.** 공격은 자동, 이동·무적 대시·오의 시점은 직접 조작한다. 침식된 닌자와 요괴가 점령한 네 전승의 전장을 돌파하고, 인법과 장비를 조합해 마지막 재앙에 도전한다. 닌자 한 명의 본체를 유지한다. 새로운 세계관 사건·주인공·세력은 추가하지 않는다.

> 가방에서 싸우는 방식을 준비하고, 전장에서 군중을 유도해 그 힘을 완성한다.

대상은 복잡한 공격 커맨드보다 빌드 실험·위치 선정·강적 대응을 좋아하는 플레이어다. 이동은 단순 도주가 아니라 일본도 사거리 유지, 적 모으기, 위험 대상 접근, 퇴로 확보를 결정한다. 잘 만든 빌드는 군중을 빠르게 쓸어내야 한다. 모든 일반 적을 개별 패턴 퍼즐로 만들지 않는다.

## 2. 조작과 기본무기 — R-INPUT

- 시작 장비는 **일본도·수리검·닌자복**이며 가방 밖 캐릭터 장비 3슬롯에 지급한다. 시작 유파 인법은 3택1을 두 번 진행해 서로 다른 인법서 2개를 고른 뒤 가방에 배치한다. 자동 공격은 장착한 무기와 배치한 공격 인법에서만 나온다. 보호/이동 인법을 고르면 별도 공격 채널이 생기지 않으므로 항상 ‘4공격’이라고 설명하지 않는다.
- 이동·대시·오의만 전투 조작이다. 수동 기본 공격, 수동 조준, 일반 스킬 단축바, 공격 때문에 멈추는 본체 모션은 넣지 않는다.
- 일본도: 가까운 목표 방향을 자동 선택해 부채꼴로 벤다. 판정 부채꼴과 VFX 방향·범위가 일치한다. 한 번의 베기에 들어온 각 대상은 1회 피해. 피해 대상 수 하드캡 대신 실제 범위로 군중 처리를 결정한다. 현재 원형 최근접 3대상 구현과 다른 설계다.
- 수리검: 자동으로 가까운 유효 적을 조준하는 직선 투사체. 기본은 첫 대상 명중 후 소멸. 맵 반대편까지 무제한 조준하지 않는다. 무효·사망 목표를 제외하고 같은 거리면 안정적 대상 ID로 결정한다.
- 무기는 R-EQUIPMENT의 장비 인스턴스에서 활성화한다. 가방의 일본도/수리검 복제나 무장과 무관한 숨은 기본 공격을 만들지 않는다. 기존 `katana`/`shuriken` ID의 저장 이력은 보존하되 신규 런의 공간 아이템 후보에서는 제외한다.
- 전투 정지·메뉴·사망·준비 중 자동 공격/대시/오의는 실행하지 않는다. UI 클릭이 전투 입력으로 새지 않는다. 복귀 때 누르고 있던 키로 오의가 발동하지 않는다.

| 초기 시험값 | 선택값 | 이유·변경 기준 |
|---|---|---|
| 일본도 | 주기 0.65초, 반경 112 월드 단위, 120도, 기본 피해 10 | 기존 주기·거리에서 대상 판정 차이만 먼저 비교 |
| 수리검 | 주기 0.75초, 조준 반경 480, 속도 560, 피해 9, 수명 1.2초 | 먼 배경 적 조준 방지·실제 탄 관리 |
| 이동 | 초당 240 월드 단위 | 기존 기본값을 비교 기준으로 유지 |
| 대시 | 2충전, 0.20초 전 구간 무적, 속도 3배, 1.5초마다 1충전 순차 회복 | 기존 기반 유지. 공격 기술로 바꾸지 않음 |
| 연속 피해 보호 | 피해 수신 후 0.35초 동안 모든 추가 피해 차단 | 겹친 군중·장판의 같은 순간 다중 피해 방지. 대시 무적과 합산하지 않고 더 늦은 종료시각 사용 |
| 입장 | 조작 가능 시점부터 1초 피해 보호, 적 생성 예고 0.8초 | 씬 전환·첫 입력 전에 죽는 문제 방지 |

정지 중 대시는 마지막 유효 이동 방향으로 실행하며, 런 시작 전 이동 이력이 없으면 화면 아래 방향을 기본으로 쓴다. 대시 중 재입력은 무시하고 충전을 쓰지 않는다. 이동/입력 버퍼는 대시 종료 후 갱신한다. 대시는 적 몸체를 통과하지만 지형 충돌을 우회하지 않는다. 무적·충전·이동 종료 시점은 PlayerController 한 곳이 소유한다.

### 획득 흐름

엘리트는 상자 토큰 + 흔적을 준다. 즉시 장착 화면을 강제하지 않는다. 보스 뒤 준비 화면에서 보상/상자를 열고 선택한다. 보스 보상은 3택1을 기본으로 하되 현재 빌드 연속성, 방금 해금한 전승, 공용 보완 중 가능한 서로 다른 후보를 제시한다. 후보가 적으면 중복 카드로 수를 채우지 않는다.

상점/상자의 인법서도 동일 인법 ID를 사용한다. 이미 가진 고유 인법서는 중복 획득시키지 않는다. 미배치 공간 아이템은 기존 REST 버퍼 6칸에 둘 수 있지만 전투력은 0이다. 출전 시 버퍼 보존 여부를 화면에 명시하고, 이 설계에서는 **미배치 버퍼를 다음 준비까지 보존**한다. 버퍼가 가득 차면 교체·판매·획득 취소를 선택하며 자동 폐기는 없다. 실물 무기/닌자복은 별도 런 장비 목록에 보관한다.

시작/추가 인법서는 모두 1×2 직사각형이다. 4유파×6종=24인법의 발동 명세는 R-NINJUTSU, 무기8종은 R-WEAPON-CONTENT가 소유한다. 기존12인법 ID는 보존하고 신규12종을 추가한다. 공간19종의 변경 매핑은 R-COMBINATION을 따른다. 오의 자원 호환성·최종 모션 자산과 실제 효과 검증은 아직 남아 있다.

공간 보조19종, 인법서24종, 캐릭터 장비9종은 별도 후보 집합이다. 런별 해금 조건을 거친 결과만 보상에서 합친다. `water_style` 같은 재료는 지원/조합 재료이며, `cheonsul_water_vein_bind` 같은 자동 기술 인법서와 다르다. 재료 툴팁에는 '자동 기술을 추가하지 않음'을 명시한다.

### 브레스 방향·귀인화 공격 제한 — 최신 사용자 변경

**오행폭주의 전방 브레스와 귀인화의 검 전용 강화는 사용자 지시다.** 2026-09-12 권장안 진행 승인으로 비검 장비를 포함한 임시 귀인검 전환도 채택했다. 아래 수치는 시험값이며 아트/실행/최종 Blueprint 승인과 구분한다.

오행폭주는 현재 전투 바라보기 방향(마지막 유효 이동 방향, 없으면 마지막 자동무기 방향, 둘 다 없으면 오른쪽)을 발동 순간 고정한다. 마우스 조준/유지 입력은 추가하지 않는다. 1.5초 동안 방출 시작점은 플레이어를 따라가되 방향은 고정하여 이동으로 부채꼴을 훑는다. 발동 전 해당 전방 부채꼴에 유효 적이 없으면 비용0. 발동 후 적을 자동 추적하거나360°로 회전하지 않는다. 후퇴 이동에도 고정 방향 유지, 다음 시전은 새 방향을 사용한다.

브레스 판정은 적 중심까지 거리≤320 및 정규화 방향 내적≥cos(30°), 시작점과 같은 위치는 포함한다. 화면 경계와 별개로 발동 후 판정 범위는 이 부채꼴만 따른다. 시점0/0.25/0.5/0.75/1/1.25초에 각 대상1회, 입퇴장으로 같은 틱 중복 피해 없음. 화상/젖음/번개 보유 여부를 틱마다 확인하되 여러 상태를 중복 가산하지 않는다. 브레스가 새 상태·반응·장판을 생성하지 않는다. 속성 기운은 혼합된 흐름으로 표현하되 이펙트 색의 수가 새 속성 규칙을 만들지 않는다. 기본 무기/선택 인법은 평소대로 자동 작동한다. 이동속도 저하나 시전 무적 없음. 대시 요청은 브레스를 취소하고 즉시 대시하며 남은 피해/자원을 환불하지 않는다.

귀인화는 장비를 실제 교환하지 않고 **임시 귀인검 공격 모드**를 적용한다. 일본도·쌍단도·나기나타·사슬낫 중 무엇을 장착해도 하나의 검 공격만 나오고 종료 시 기존 무기 동작으로 돌아온다. 검 장착 때만 발동하는 대안은 폐기한다. 빈 근접 슬롯/알 수 없는 장비 ID는 정상 출전 검증에서 거부하며 임시검으로 손상 장비를 숨기지 않는다.

‘검만 사용’은 공격 출력 제한이다. 귀인화 중 투사무기·공격 인법·식신/분신 공격·피해 장판·화상/독·조합 부가 피해를 중단한다. 플레이어가 이미 발사한 비검 투사체/예약 피해도 취소하며 만료된 공격을 종료 때 재생하지 않는다. 원래 공격 쿨다운 잔여시간은 동결하고 복귀 시 이어가며 밀린 공격을 몰아 쏘지 않는다. 기존 피해 영역·소환체는 정상 수명만 흐르고 공격 권한은 없으며 만료 시 제거한다. 적이 사용하는 효과에는 영향 없음.

닌자복·수치형 방어/이동 보너스·현재 보호막과 비피해 상태의 남은 지속은 유지한다. 책에서 새로운 보호막/결계/대시 보조를 발동하는 것도 변신 중에는 중단한다. 플레이어 이동·무적 대시는 그대로 가능하고 대시가 귀인화를 취소하지 않는다. 변신 무적/자동 회복/피해 감소를 새로 추가하지 않는다. 종료/사망/전장 전환은 모드 토큰을 한 번 해제하고 원래 공격 권한을 복원한다. 일시정지는 모드 지속과 모든 관련 시계를 함께 정지한다.

### 발동 거래·입력·중단

1. 키/패드/터치 버튼 모두 Host의 동일 요청 경로를 사용한다. 새 누름만 허용하고 누름 유지·메뉴 닫기 입력을 재사용하지 않는다.
2. 실제 발동 직전 시작 유파·생존·전투 상태·pause·지속 중 여부·충분한 자원을 다시 검사한다. 발동 목표는 화면에 보이고 공격 가능한 적만 허용한다. 봉마/흑영은320, 천술은 전방 브레스 부채꼴, 귀인은 임시검168 이내에 최소1명 필요하다. 충전 조건과 발동 조건은 서로 다르다.
3. 대상/효과 생성 계획이 유효할 때 비용과 효과를 한 번에 확정한다. 대상 없음·생성 실패·중복 요청에는 비용0, 이유 표시. 준비 완료여도 대상이 없으면 `READY_NO_TARGET`이다.
4. 성공 후 적이 죽거나 범위에서 나가면 환불하지 않는다. 봉마 식신과 귀인검은 남은 지속 동안 새 대상을 찾는다. 브레스는 원래 방향을 유지하고 빈 틱을 건너뛰되 지속을 늘리지 않는다. 추가 확정 요청은 거부한다.
5. 일시정지는 자원·효과 지속·공격 간격·보너스 내부주기를 함께 정지한다. 사망/스테이지 이탈은 오의 소환체·미실행 타격을 정리한다. 출전 준비로 넘어가면 남은 자원은 유지하되 지속 효과는 끝난다. 무료 충전/비용 환불 없음.

백귀진 식신은 오의 중에만 존재하는 독립 소환체다. 백귀식신 책을 선택한 경우 책 식신은 별도로 그대로 작동하며 오의가 이를 영구 증폭하지 않는다. 귀인화는 임시검 모드이며 기존 맥동을 추가하지 않는다. 책 미선택 상태의 평상시 식신/결계/귀혈 맥동/암영침/원소 교대는 제거 대상이며 무료 기본 기술로 남기지 않는다. 현재 코드의 세부 동작을 이미 교체했다는 뜻은 아니다.

## 6. 가방·인접·조합 — R-BAG

- 시작 사용 면적 3×3, 기술 보드 상한 6×6. 확장 주머니를 획득·배치해 실제 사용 칸을 넓힌다. 처음부터 6×6을 사용할 수 없다.
- 아이템/가방 90도 회전, 직교 인접, L/T 가방, 특수 가방 한 칸 이상 겹침 활성화는 유지한다. 대각선 인접·전투 중 가방 편집은 없다.
- 일본도·수리검·닌자복은 장비 슬롯에, 선택한 시작 인법서 2개는 가방에 놓는다. 각 책 1×2로 4/9칸을 쓰고 5칸이 남는다. 예시 행은 `A B 빈 / A B 빈 / 빈 빈 빈`. 책 없는 가방에서 무기는 작동할 수 있지만 시작 선택을 생략한 정상 신규 런으로 취급하지 않는다.
- 가방 칸은 공간 예산, 활성 인법 최대 4개/타 유파 최대 1개는 발동 복잡도 예산이다. 둘 다 검사하며 공간 부족/기술 수 초과/타 유파 수 초과를 별개로 안내한다.
- 일반 보조 장비는 공통 수치, 무기 비전은 해당 기본무기, 인법서는 해당 자동 기술, 유파 증표는 시작 유파 자원/특성을 강화한다. ‘인법 피해’는 일본도·수리검을 강화하지 않는다.
- 동일 비전 여러 개의 수치 보너스는 합산하되 해당 기본무기 비전 계열 증가 합계는 초기 +60% 상한, 관통/연쇄 같은 행동 효과는 1회만 적용. 인법서 중복 장착 불가. 모든 피해는 적용 범주별 보너스를 한 번만 계산하고 재료와 조합 결과를 동시에 집계하지 않는다.
- 인접 규칙은 아이템에 표시된 효과만 발생. 물·불·칼 태그가 이웃한다고 미등록 새 기술이 자동 생성되지 않는다. 비교 화면에 발동 인법, 피해 범주, 범위, 지속, 잃는 효과를 표시한다.

부가 번개/폭발은 고정 시험 피해에 대응 근접/투사 태그 보너스만 적용하며 장비 강화·비전의 원타 증가를 재적용하지 않는다. 같은 결과는 고유1개, 미리보기/버퍼에서는 효과0. 재료와 결과 동시 집계 금지. 별도 폭탄 자동 채널과 옛 비전의 인접 관통/+8%는 폐기한다. 직교 인접은 조합 가능 조건으로 유지한다. 결과 크기는 water_mist2×2, thunder_blade1×3, explosive_bomb2×2이며 들어갈 곳이 없으면 재료를 소비하지 않고 재배치/취소한다. 판매가는 소비한 재료 정의 가격 합의50% 내림, 강화한 실물 장비 가격은 포함하지 않는다. 재료 구매 단계의 유파 패키지 개방은 기존 전장 안정화 경로를 따르되, 인법 흡수/포기와 별도 자격이다. 인법 포기로 공용 조합 자체를 막지 않는다.

물안개와 이동 보너스는 가산 후 기본속도의 1.6배 상한(대시 배율 적용 전), 피해 감소는 장비/결계/운명 효과를 가산한 뒤 최대 60%, 확률 회피는 최대 40%로 제한하는 초기안이다. 최대 HP 감소는 기본 HP의 25% 미만으로 낮추지 않는다. 회피로 피해를 막은 사건은 피격 보상을 만들지 않는다. 경계값·중복·원천 해제 후 원복을 시험한다. 상한은 성장 곡선 시험값이지 현 코드 보장값이 아니다.

준비 중 장비 교체·배치·회전·조합 결과는 미리보기일 뿐이다. 출전 확정에서 장비·강화 단계·가방·활성 인법·운명·다음 전장·비용을 한 번에 검증해 전부 적용하거나 전부 되돌린다. 반복 클릭/저장 실패/공간 불법 시 일부 재료나 골드만 사라지면 안 된다. UI는 규칙의 주인이 아니다.

## 7. 스테이지 여정·흔적·운명 — R-RUN

### 클리어 후 흔적 선택 — R-TRACE

**2026-09-20 최신 요청 우선:** 흡수=인술 획득 자격은 유지한다. 강화의 보상은
단순 단계+1이 아니라 선택 장비에 유파 고유 효과를 더하는 방향으로 변경한다.
아래 단계+1 표와 흔적만이 강화 공급원이라는 불변식은 이전 구현 이력이며
새 성장 설계를 지시하지 않는다. 시작 유파의 해금/책 보존, 흔적 한 번 처리,
준비 거래와 출전 거래 분리, 장비의 가방 미점유는 변경 요청이 없어 보호한다.

- 최신 요청의 선택 시점은 스테이지 보스 클리어 후다. 아래 옛 전장 회수/보스 게이트 표는 현 구현과 비교할 이력이며, 최종 단계 통합 전에는 신규 구현 명령으로 사용하지 않는다.
- 타 유파 흔적: **흡수**는 해당 런 인법 획득 풀을 해금한다. **장비 강화**는 해당 유파 인법을 이번 런에서 해금하지 않고, 현재 장착한 근접무기/투사무기/닌자복 중 정확히 하나를 강화한다. 둘을 동시에 받지 않는다.
- 강화한 흔적은 같은 런에서 나중에 흡수로 바꿀 수 없다. 전장 완료·최종전 진입용 회수 기록은 어느 선택도 동일하게 진행한다. 인법 해금 포기를 방문 실패로 취급하지 않는다.
- 강화 선택 → 장착 장비 3개 비교 → 대상 1개 선택 → 최종 확인. 취소하면 흔적/단계 소비 없이 앞 화면으로 돌아간다. 흔적 사용 기록과 선택 장비 단계 변경은 같은 거래다. 재클릭/복원으로 중복 강화하지 않는다.
- **USER_APPROVED — 시작 유파 예외:** 시작 유파 인법의 해금과 이미 획득한 인법서는 유지한다. 시작 유파의 흔적에서는 중복 해금인 ‘흡수’를 제시하지 않고 장비 강화 대상 선택으로 진입한다. 강화해도 시작 인법을 삭제·봉인·강제 해제하지 않는다. 가방에서 빼면 비활성화되는 일반 배치 규칙은 그대로다.
- 미해금 타 유파만 흡수/강화의 양자택일이다. 강화 확인 문구는 ‘이 유파의 인법은 이번 런에서 획득할 수 없습니다’. 시작 유파에는 ‘시작 유파 인법은 유지됩니다’를 표시한다. 인법 해금 포기를 유파 공통 조합 재료의 획득 금지나 최종전 진입 금지로 확장하지 않는다.
- 흔적 거래는 준비 화면에서 먼저 저장 확정하되 전투 중 즉시 능력을 바꾸지 않는다. 이후 가방·장비 배치 출전 거래가 강화된 소유 장비를 소비한다. 출전 취소는 이미 확인한 흔적 결정을 되돌리지 않으며 두 확인의 의미를 화면에 구분한다.

| 조건 | 제공 행동 | 인법 접근 결과 | 장비 결과 |
|---|---|---|---|
| 시작 유파 / 미사용 흔적 | 장비 1개 선택 | 시작 해금·보유 책 유지 | 선택 인스턴스 단계 +1 |
| 타 유파 / 미해금 / 미사용 흔적 / 흡수 | 흡수 확인 | 해당 런 후보 해금, 자동 지급 아님 | 변화 없음 |
| 타 유파 / 미해금 / 미사용 흔적 / 강화 | 장비 1개 선택 후 포기 확인 | 해당 런 인법 후보에서 제외 | 선택 인스턴스 단계 +1 |
| 어느 유파든 이미 처리된 흔적 | 처리 결과 조회만 | 변경 없음 | 중복 강화 없음 |
| 대상 미장착·단계 상한·revision 불일치 | 확정 거부·대상 다시 선택 | 변경 없음 | 소비 없음 |

유효한 새 런에서는 각 전장을 한 번만 완료하고 흔적도 4개만 얻는다. 강화는 그 흔적만 공급하므로 처리 전 최대 누적3회, 장비별 상한4회에 정상적으로 막힐 수 없다. 손상 저장이나 중복 요청 때문에 이 불변식이 깨지면 대체 보상/무료 추가 해금으로 숨기지 않는다.

```text
메인 → 새 게임 → 시작 유파 → 미방문 전장 선택
→ 군중 생존 → 엘리트 → 흔적 회수 → 보스 예고 → 보스 격파
→ 보상/전승 안정화 → 한 화면의 준비(보상·가방·상점·조합·다음 전장·운명)
→ 출전 확정 → 다음 스테이지
→ 네 전장 각 1회 완료 → 최종 준비 → 재앙 보스 → 정산/각성/재도전
```

스테이지는 진행 순번 1~4, 전승은 적·보스 특성이다. ‘스쿨 2’ 같은 표현은 쓰지 않는다. 목표는 네 전장 약 20분 전투이며 준비·최종전은 별도. 시간 초과만으로 강제 패배시키지 않는다.

| 전장 시간·단계 | 플레이 목적·규칙 |
|---|---|
| 0~30초 | 세 자동 공격과 기본 추격 적 확인. 대형 패턴 없음 |
| 30~105초 | 추격 적 역할 혼합. 좁은 길 강제·원거리 일반 적 없음 |
| 105~165초 | 군중 압박 증가. 갑작스러운 발밑 생성 금지 |
| 약 165초 | 엘리트 등장 경고 |
| 약 180초 | 엘리트 등장. 2개 패턴을 순차적으로 학습 |
| 엘리트 사망 | 상자 토큰·비소멸 흔적. 새 일반 스폰 일시 중지, 기존 적·시간은 유지 |
| 흔적 회수 | 접촉 반경 40 안에 들어가면 즉시 회수. 채널링/연타/추가 전투 보상 없음 |
| 약 260초 이후 | 엘리트 격파+흔적 회수 후 보스 경고. 늦게 회수해도 최소 8초 경고 보장 |
| 270초 이후 | 시간·격파·회수·경고 게이트 모두 충족하면 보스 등장 |
| 약 300~330초 | 보스 처치 목표. 강제 승패 시각 아님 |

흔적은 ‘엘리트에게서 빼앗은 전승의 열쇠’로 설명한다. 전장에서는 보스 진입, 귀환에서는 해당 전승 획득 후보 해금에 쓰인다. 소멸·몰래 타이머·골드 보상과 겹치지 않는다. 화면 밖이면 방향 표시, 남은 목적은 ‘흔적 회수’ 한 줄로 보인다.

흔적 회수 즉시 누적 스폰을 몰아서 내지 않는다. 일반 스폰 재개는 정상 주기부터이며 보스 경고 때 다시 중지한다. 엘리트/보스 도중 일반 스폰은 중지, 이미 있던 군중은 남는다. 최대 몹 수를 제한하는 것이 아니라 진행 게이트별 생성 권한이다. 회수 단계가 반복적으로 불필요하게 느껴지면 자동 회수와 비교하되 이번 기본안은 직접 접근 회수다.

운명은 유지하되 별도 이동 화면 대신 준비 화면의 선택 카드로 둔다. 현재 다섯 운명 ID·장단점은 기존 카탈로그를 기준으로 유지한다. 미선택 운명이 세 개 미만이면 남은 후보만 표시한다. 이미 가진 운명을 복제하거나 네 번째 준비를 막지 않는다. 출전 버튼의 이름은 ‘운명’이 아니라 **출전 확정**이며 네 전장 완료 후에는 **최종전 출전 확정**이다. 최종 준비는 다섯 번째 전장 선택 없이 백팩·운명을 확정한다. 운명을 골라도 즉시 출전하지 않는다. 재입장은 미확정 준비 상태를 보존하고, 뒤로 가기는 런 자체를 끝내지 않는다.

엘리트는 두 기술을 차례로 보여준다. 보스는 처음 두 기술을 최소 1회씩 보인 후 세 번째를 사용한다. Stage1에서는 세 번째도 단일 위협, 2에서는 한 가지 상호작용, 3~4에서는 최대 두 위협 조합. Stage4의 추가 숙련은 세 번째 기술의 변형이지 네 번째 불명 패턴 추가가 아니다.

패턴 공통 초기값은 다음과 같다. 전승별 이미지는 이 판정 데이터를 표현하며 반대로 이미지를 보고 임의 판정을 만들지 않는다. HP는 엘리트 360/유파 보스 900/최종 보스 1800을 첫 비교값으로 두고 목표 처치시간에서 역산한다. Stage2/3/4의 HP 배율은 1.2/1.45/1.7, 피해는 1.05/1.1/1.15, 이동속도·전조는 기본 유지한다. 성장 빌드 DPS를 측정해 조정할 값이며 검증된 난이도 곡선이 아니다.

| 공유 패턴 | 판정·수명 초기값 | 회피·악용 방지 |
|---|---|---|
| 직선 돌진/낙뢰 | 길이 280·폭 56, 18 피해 1회 | 확정된 방향 변경 없음, 한 시전 중 중복 접촉 피해 금지 |
| 넓은 베기 | 반경 160·120도, 20 피해 1회 | 시전자 근처 360도 피해로 대체하지 않음 |
| 부적/암영침 부채꼴 | 60도 내 5발, 속도 220, 수명 2초, 12 피해 | 발사체 간 틈 확보, 발사 후 유도 없음 |
| 지연 원/표식 폭발 | 반경 96, 18 피해 1회 | 위치 고정 뒤 실제 보행 탈출 시간 확보, 겹친 피해는 피격 보호 적용 |
| 원형 충격파 | 반경 80→240, 0.8초 확장, 안전 틈 90도, 18 피해 | 링 바깥/안쪽이 동시에 즉사 영역이 되지 않음 |
| 결계 파열 | 반경 120, 발동 시 18 피해 1회 | 남는 문양은 피해 없는 종료 표시; 피해 바닥이면 별도 수명 명시 |
| 식신 소환 | 2체, HP 20·속도 플레이어의 0.6배·접촉 피해 6·최대 6초 | 죽거나 수명 종료 시 제거. 재소환은 기존 식신 종료 후. 일반 군중 무제한 규칙과 별개인 임시 보스 기술 |
| 사라짐/재등장 | 사라짐 0.8초, 플레이어에서 180 이상 떨어진 예고 위치 | 재등장 자체 피해 없음, 후속 베기 전 새 전조 확보 |

보스 식신 패턴 슬롯은 식신 전부 종료까지 유지한다. 시전자 사망 때 식신도 정리한다. 패턴 발동 실패/취소는 보상·피해를 만들지 않으며 다음 합법 후보를 선택한다. 도달 가능한 경로 계산이 실패하면 강행하지 않고 대기한다.

최종 재앙 보스는 네 유파의 배운 패턴을 차례로 재사용한다. 4종 동시 사용 금지, 동시 강한 위협 2개 이하. 회수한 전승의 지원은 대응 힌트·짧은 기회 제공으로 표현하고, 최종 피해와 승리는 플레이어 빌드가 결정한다. 별도 네 개 새 오의 획득은 없다.

## 9. 군중·패턴 공정성·성능 — R-FAIRNESS

- 일반 스폰이 허용되는 동안 최소 10마리 유지. 네 방향 순환 대신 플레이어 주변 고리의 무작위 각도·거리. 최대 몹 수 하드캡·오래됐다는 이유의 자동 삭제는 넣지 않는다.
- 최소 유지 계산은 살아 있는 일반 적 + 생성 예고 중 예약 수를 합산한다. 입장 때 10마리를 예약하고 0.8초 예고 뒤 생성하며, 처치 후 부족분도 같은 예고를 거쳐 보충한다. 예고 지연 중 잠시 10마리 미만인 것과 최소 유지 목표를 구분한다. 매 프레임 부족분을 중복 예약하지 않는다. 강적/흔적 단계로 스폰 권한이 닫히면 미발동 예약은 취소하고 재개 때 정상 주기부터 다시 계산한다.
- 화면 밖이며 플레이어에서 480 이상 720 이하인 점을 우선 샘플링하는 것을 초기값으로 둔다. 카메라 크기 때문에 불가능하면 최소 거리/화면 밖 조건은 완화하지 않고 고리 바깥 반경을 확대한다. 적을 생성한 뒤 순간 이동으로 숨기지 않는다.
- 기본 보충은 기존 1초당 3마리를 비교 기준으로 유지. 강한 패턴 때문에 일반 적 수를 조용히 캡하지 않는다. 위협은 속도·구성·생성 페이즈로 조정하며 플레이어가 강해졌다고 즉시 적 HP를 상쇄 증가시키지 않는다.
- 강한 패턴 예산은 Stage1~2에 1개, Stage3~4와 최종전에 2개. 전조 시작부터 마지막 피해/영역 종료까지 슬롯 유지. 일반 접촉 적은 이 패턴 슬롯을 쓰지 않는다.
- 슬롯 부족 시 공격 전 대기/이동. 보이는 전조를 취소 없이 늘이거나 이미 확정된 궤적을 추적 변경하지 않는다. 시전자 사망/씬 종료/런 포기 때 슬롯과 위험 영역을 함께 해제. 일시정지는 취소가 아니라 전조·위험 영역·슬롯·시계를 함께 동결하고 재개한다. 메뉴를 반복해서 열어 보스 공격을 제거할 수 없다.
- 초기 전조 0.9초, 마지막 최소 0.65초 위치·방향 고정, 타격 후 회복 0.7초 이상, 같은 시전자 패턴 간격 3초 이상. 영역 피해 최대 지속 2초. 고정 구간은 `max(0.65초, 안전 경로 길이 / 현재 보행속도 + 0.15초)` 이상이며 전체 전조는 고정 구간 + 0.2초 이상으로 발동 전에 정한다. 보이는 전조 도중 숨은 재조정은 없다. 최종 수치는 아니다.
- 위험 영역의 합집합과 충돌 여유를 계산해 보행으로 도달 가능한 탈출 경로가 최소 하나 있어야 패턴 발동. 대시가 0이라고 자동 약화시키지는 않지만 대시 필수 즉사 패턴은 기본안에서 제외한다.
- 예: 반경 96 영역 중앙에서 플레이어 반경 14까지 벗어나는 데 속도 240이면 약 0.458초가 필요하다. 위치 고정 0.3초는 불충분하므로 채택하지 않는다. 0.65초도 이동 장애물/둔화가 있으면 자동 안전 판정이 아니며 위 경로 검사를 통과해야 한다.
- 첫 전조가 카메라 밖인 큰 공격은 발동 대기 또는 화면 경계 방향+음향 예고 후 충분한 이동 시간을 준다. 위험 원·부채꼴·직선은 실제 피해 도형과 같은 데이터로 생성한다.
- 피격 색·사운드·방향, 전조 형태·문양·시전자 준비 자세를 중복 단서로 쓴다. VFX 강도 감소가 피해 경계·전조를 숨기면 안 된다.
- 엔진 최적화는 기존 WaveSpawner/Actor 책임 유지 → 공간 후보 조회 → 갱신 분산 → 풀링/렌더 묶음 순서로 측정 후 선택. MultiMesh는 렌더 최적화이지 AI/충돌 자동 최적화가 아니다. 무한 수를 유한 기계가 항상 처리한다는 보증은 하지 않는다.

성능 시험 지점은 일반 적 100/300/600/1000개와 지속 누적 구간으로 기록한다. 이 수는 허용 최대치가 아니라 프로파일링 표본이다. 목표 장비를 확정한 뒤 프레임 시간·최악 구간·메모리 증가를 측정한다. 실패 시 데이터 구조·표현 비용을 교정하며 사용자 수 제한을 몰래 도입하지 않는다.

## 10. 경제·각성·도감·메뉴 — R-META

- 런 중 성장의 주인은 보상·가방·인법·조합·운명이다. 별도 경험치 레벨업 3택1을 새로 추가하지 않는다. 현재 RewardOrb는 전투 기록용이며 소울·골드·흔적·인법 경험치가 아니다. 처치 구슬은 자동 접근하고 5초 뒤 사라지는 기존 기준을 유지하되 놓쳐도 필수 성장/진행을 잃지 않는다.
- 기존 연속 처치창 2.5초와 결과 STYLE 기록은 유지하되 전투 HUD를 점수판으로 덮지 않는다. 결과에는 최고 연속 처치·처치 수·회수 구슬 수를 설명과 함께 표시한다. 점수가 공격력이나 소울 지급을 자동 증가시키지 않는다.

- 런 골드는 상점·가방 확장에 쓴다. 현재 경제 정책(일반 처치 확률 수입, 엘리트·보스 수입)을 첫 비교 기준으로 유지하고 가격·수입을 함께 관측한다. 흔적은 별도 돈이 아니다.
- 상점 첫 준비에는 현재 살 수 있는 확장 주머니 후보를 보장한다. 돈이 부족하면 숨기지 않고 필요 금액 표시, 구매 없이 출전 가능. 골드가 없다고 필수 진행 해금이 막히지 않는다.
- 준비 진입 회복은 prepare_session_id마다 한 번만 적용한다. 같은 준비 화면을 닫았다 열거나 이어하기를 반복해 회복을 다시 받지 않는다. 회복 효율은 운명·장비 modifier를 적용한 뒤 HP 상한까지만 회복한다.
- 영구재화 이름은 **닌자소울**, 메뉴 이름은 **각성**. 현재 wallet은 비용 소비 중심이므로 새 지급·정산 기능이 이미 있다고 주장하지 않는다.
- 새 설계 지급안: 런 종료 때 서로 다른 유파 보스당 1소울, 최종 재앙 승리 +2소울. 첫 보스 이전 실패라도 그 런에서 엘리트를 최초 1회 격파했다면 위로 1소울(보스 소울과 중복하지 않음). 시간만 버티는 무한 파밍 없음.
- 기존 1소울 재도전은 유지 후보: 런당 1회, 마지막 출전 확정 checkpoint로 복귀. 재도전은 정산 종료가 아니며, 최종 포기/승리에서만 지급. 동일 run_id 정산 중복 금지. 재시도 전 얻은 자격과 checkpoint 자격의 합집합으로 보스 중복 지급 방지.
- 각성의 첫 확대는 수평 선택: 3소울로 시작 지원 선택 기능 해금, 체술단련/호신 부적/인법단련 중 1개를 시작 가방에 지급. 기존 크기·효과 사용. 한 번 해금하면 다음 런마다 1개 선택 가능하며 판매 가격은 0. 필수 조작·기본 인법·대시는 소울로 잠그지 않는다. 무한 공격력/HP 업그레이드 트리는 보류한다.
- 도감은 적·인법서·장비의 실제 동작, 획득, 조합, 보스 제어 예외를 설명한다. 런 흐름 일지를 대신 넣지 않는다. 발견 전에도 핵심 조작·위험 대응 설명을 숨기지 않는다.
- 메인 메뉴: 새 게임 / 이어하기 / 각성 / 도감 / 설정 / 종료. 이어하기는 검증 가능한 checkpoint 없으면 비활성 이유 표시. 새 게임이 기존 저장을 대체할 때 확인. 종료 전 저장 완료 여부 표시.
- 워드로고 옆 작은 4조각 닌자 메달은 유지 방향. 메달 높이는 제목의 ‘닌’ 글자 수준. 약속 문구·유파별 큰 패널은 메인에 다시 넣지 않는다. 2026-09-11 이미지 후보 제작은 허용됐으며 정본 등록·runtime 교체는 최종 승인 뒤다.

## 11. 화면·모션·VFX 제작 입력 — R-PRESENTATION

화면별 배치는 기존 화면 블루프린트를 확장한다. 하단 일반 스킬바는 없음. 상단에 대시 충전·플레이 시간·오의 상태·설정, 체력은 기존 피격/위험 가시성 정책과 통합한다. 터치는 별도 이동·대시·오의 접근 경로가 필요하지만 일반 인법 버튼을 만들지 않는다.

| 대상 | 필요한 상태 | 게임 사건과 연결 |
|---|---|---|
| 플레이어 | 대기·이동·대시·피격·사망 | 공격 모션 없이 이동 유지. 대시 시작/무적 종료와 표현 일치 |
| 일반 적 | 이동·피격·사망·생성 예고 | 발 접점·그림자·속도 일치, 접촉 피해 시점 분리 |
| 엘리트·보스 | 이동·준비·방향 고정·발동·회복·피격·사망 | 패턴 시간표가 애니메이션을 구동; 이미지 프레임이 판정의 새 주인이 되지 않음 |
| 인법 | 시전·이동/영역 유지·명중·만료 | 실제 영역/상태가 끝나면 효과도 종료. 독·결박·결계 모양 구별 |
| 바닥·소품 | 무한 반복 바닥 / 개별 나무·등잔 | 바닥에 랜드마크 굽지 않음. 발밑 대비와 전조 가독성 확보 |

이미지 모델은 래스터 원화/필요 프레임, Aseprite는 적합할 때 정렬·프레임·타이밍·PNG+JSON 내보내기에 사용한다. 후보 공간에서만 작업하고 원본·발 접점·알파·좌우 방향·무기 크기·준비→발동→회복 연속성을 검사한다. Aseprite 사용이 픽셀 그림체 채택을 뜻하지 않는다. 프레임 수·해상도는 실제 카메라/속도 비교 후 정하며 지금 임의의 4×4 시트로 고정하지 않는다.

## 12. 구현 가능성·데이터·복구 경계

**판정: 정적 구현 경로는 FEASIBLE / 상세 입력은 SPECIFIED_FOR_REVIEW.** 기존 Godot 4.x 소유자·ID·상태·저장·실패 경로와 P01~P08 인수 시험까지 연결했다. 최종 설계 승인 후 P01부터 착수할 수 있다. 전체 제품의 BUILD_READY·ASSET_READY·runtime 성공을 뜻하지 않으며, 아트 LOCK·실제 모션/성능·저장 실패 주입은 각 구현 패키지의 gate다. 새 엔진·유료 서비스·서버·전역 autoload는 요구하지 않는다.

저장: 현재 RunResumeCodec schema 1은 새 혼합·아이템 의미를 모두 담지 못한다. schema 2의 명시적 읽기 정책·거래·복구는 [구현 입력 명세](NINJA_SURVIVAL_IMPLEMENTATION_PACKET.md)가 소유한다. 구형 진행 중 런은 의미가 달라 자동 변환하지 않고 원본 보존·호환 불가 안내·새 런 선택으로 처리한다. 구형 지갑 잔액은 별도 검증 후 1회 이관 가능하다. 알 수 없는 ID/버전, 인법 중복·면적 초과·해금 불일치는 부분 복원 없이 실패한다. 이행 검증 전 별도 테스트 user 데이터 경로를 사용한다.

공간 장착·운명·경로·비용·활성 인법·버퍼를 하나의 확정 snapshot으로 만든 뒤 저장한다. 준비 도중 임시 이동은 확정 저장을 바꾸지 않는다. 실행 중 강제 종료 후 이어하기는 마지막 확정 checkpoint라는 약속을 표시한다. 프레임마다 실시간 전투 저장은 추가하지 않는다.

## 13. 학습·검증·작업 순서

첫 학습: 이동으로 무기 결과 확인 → 적이 접근할 때 대시 → 첫 엘리트에서 전조/후딜 → 오의 조건·시점 → 보스 뒤 보상·가방 변경 → 다음 전장에서 변화 확인. 안내는 짧고 재열람 가능하며, 팝업을 닫았다는 사실을 학습 PASS로 쓰지 않는다.

### 수치 조정용 기준

| 질문 | 비교·관측 | 반증/중단 기준 |
|---|---|---|
| 가방이 행동을 바꾸는가 | 같은 seed/적/시작 스탯, 배치만 바꾼 두 빌드 | 사용자가 달라진 효과·선택 이유를 설명하지 못하거나 두 빌드 경로가 무의미하게 동일 |
| 군중 처치가 시원한가 | 일반 적 처치 분포·접근 거리·자기보고를 함께 관찰 | 약한 적이 체력 스펀지거나 도망만 해야 함 |
| 패턴이 공정한가 | 대시 0/1/2충전, 화면 경계, 겹친 장판, 입력 지연 | 걷기 탈출 경로 없음·예고와 다른 피해·첫 프레임 즉사면 MUST_FIX |
| 혼합 선택에 대가가 있는가 | 순수유파 vs 보조유파 동일 장비 예산 | 혼합이 모든 상황에서 우월하면 순수유파/슬롯 비교 재검토 |
| 준비가 피곤한가 | 첫/후속 준비의 시간·취소·잘못 확정·설명 요구 | 기능 설명보다 메뉴 이동에 오래 쓰거나 실수 복구 불가 |
| 각성이 강제 파밍인가 | 미해금 계정·해금 계정 같은 전장 비교 | 기본 계정으로 공정한 공략 자체가 불가능하면 성장/난이도 재검토 |

사람 검증은 비교 순서를 교차한 소규모 탐색부터 시작하되 표본 규모·플레이 시간은 모집 조건과 exact build에 맞춰 별도 기록한다. 이 문서로 모집·외부 메시지를 보내지 않는다. 취향·감정·이해도는 로그만으로 확정하지 않는다.

### 제작 착수 전 검사와 완료 증거

1. 상세 설계 검토 → 상태/반응 충돌 교정 → 구현 입력 명세 → 사람용 Blueprint.
2. 천술 대표 구간의 두 빌드·적/보스 1세트를 먼저 검수하되, 최신 요청에 따라 네 유파의 필요한 이미지 후보와 전체 화면 아틀라스도 준비한다.
3. 후보의 실제 알파·셀·프레임 검수 → 사용자 최종 LOCK. 생성 성공이나 PDF 삽입을 ASSET_READY로 간주하지 않는다.
4. 별도 구현 범위 확정 후 규칙별 단위 시험: 동시 공격·상태 틱·중복 처형·쿨다운·거짓 인접·저장 손상·취소·해금 순서.
5. 통합 시험: 각 시작유파×24전장순서(96조건), 최종전, 중복 보상/재도전·중단 복구. 전체 구간을 매번 실시간 재생하는 대신 도메인 상태 시험과 실제 대표 런을 구분.
6. 정확한 Godot 빌드 import/GUT → 실제 런 화면/입력/성능 → 사람 경험/기기 검증. 새 디자인 시험은 모두 아직 NOT_RUN.

## 14. 추가·수정·보류와 독창성 판정

| 현재 문제 | 조치 | 기대효과·trade-off |
|---|---|---|
| 이름만 다른 즉시 피해 인법 | 결박·보호·독·처형을 실제 상태로 분리 | 유파 의미 강화, 상태 예외 검사 증가 |
| 가방 일본도가 유파 피해 증가 | 무기 비전으로 역할/표시명 정렬 | 강화 결과 이해, 구버전 의미 이행 필요 |
| 시작유파 인법만 허용 | 제한 혼합 + 배치에서 장착 도출 | 전승 회수·가방 연결, 데이터/저장 변경 필요 |
| 각 단계가 별도 메뉴처럼 느껴짐 | 준비 화면에 통합, 원자적 확정 유지 | 메뉴 왕복 감소, 한 화면의 정보 계층 검수 필요 |
| 무한 군중에 무한 강공격까지 겹침 | 개체 수와 패턴 예산 분리 | 군중 쾌감·대응 가능성 공존, 안전 경로 계산 필요 |
| 새 이미지부터 일괄 생산 | 실제 역할/전조/상태 확정 후 대표 세트 | 재작업 감소, 초기 눈에 보이는 생산 속도는 느림 |
| 임의 대시 공격·자유 연쇄 엔진·무한 스탯 메타 | 보류 | 핵심 조작·제작성 보호 |

SWOT: 강점은 기존 가방/원자적 확정/유파 runtime, 약점은 설명과 효과의 불일치, 기회는 공간 준비가 이동 판단을 바꾸는 경험, 위협은 가까운 경쟁작과 과도한 콘텐츠 비용이다. 대응은 ‘기존 소유자 재사용 → 동작 의미 정렬 → 대표 두 빌드 비교 → 검증 후 확대’다. 닌자 외형이나 조합이라는 소재만으로 독창성·흥행을 주장하지 않는다.
