# Notion → repository migration

This directory preserves the current `닌자의 신` Notion structure and its
current working records as a repository-readable migration archive.

- It is a read-only snapshot, not a second product-canon owner.
- Signed Notion file URLs are deliberately redacted because they are temporary
  credentials. Their durable repository binaries, SHA-256 values, source
  provenance and consumers are recorded in the mapped asset manifests.
- Old work-plan rows and one deferred old Ninja Soul record are intentionally
  excluded; see `MIGRATION_MANIFEST.md` for the exact exclusion audit.

Read `MIGRATION_MANIFEST.md` first for the coverage report and active-owner
mapping. Snapshot files retain the Notion hierarchy, properties and content
needed to reconstruct the non-legacy project surface.
