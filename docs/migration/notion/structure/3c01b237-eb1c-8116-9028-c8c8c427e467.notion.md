## 2026-08-28 · 천술류 P0 전투 레퍼런스 해석 교정
기존 `SCRREF-BATTLE-CHEONSUL-02`는 탑다운 구도, 열린 전투 중심, 작은 SD 플레이어/적/위험 계층, 제한된 HUD 영역에만 계속 사용합니다. 다만 그 이미지의 보라 중심 천술류 효과와 지속 텍스트 상태/상시 적 HP의 인상은 현행 정본에서 **SUPERSEDED**입니다.
- 천술류 = 청색 + 호박/주황
- 흑영류 = 보라 + 검정
- 상태 = 작은 실루엣 구분 아이콘
- 적 HP = 기본 숨김, 피격 직후 적 하나만 표시
이 문제는 첫 보드에만 적용됩니다. 사용자는 A 구성의 개정 보드에서 `Trace → Boss`를 독립 패널로 선택했고, 현재 이 보드를 기획 점검용 참고 자료로 유지합니다. 천술류 Core panel의 후속 검토에서는 플레이어가 자동 `WET` 시전 지점에 남는 짧은 고정 청색 준비 결계로 적을 유도하고, 다음 자동 `SHOCK`의 호박/주황 연쇄 결과를 읽는 DEC-027/028 Player Promise를 보여야 합니다. 다만 개정 보드는 여전히 `REFERENCE_ONLY GENERATED_EXPLORATION`이며, 해당 공간 조건의 정확한 형태, Trace와 일반 보상의 시각적 구분 및 실제 6×6 Workbench 사용성은 제품 결정·Human Usability 검증 전까지 미확정입니다.
