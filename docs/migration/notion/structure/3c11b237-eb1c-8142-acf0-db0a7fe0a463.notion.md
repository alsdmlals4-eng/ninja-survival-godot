## DEC-2026-08-20-016/017 · 유파 전승 흔적과 잠식 생태계 · APPROVED
- `유파 흔적`은 죽은 자의 영혼이 아니라 각 유파의 전장에 남은 **전승·술식·기량·의지의 잔향**입니다.
- 플레이어는 한 Run에서 봉마·천술·귀인·흑영 흔적을 각각 하나씩 회수하며, 흔적은 Boss를 만나기 전 해당 유파 전장의 핵심 진행물로 획득합니다.
- 해당 유파 Boss를 격파하고 공동 지부로 귀환하면 흔적이 안정화되어 이후 Run의 빌드 방향에 작은 영향을 줍니다.
- 4번째 유파 Boss 이후 네 흔적은 마지막 휴식에서 하나의 **최종 전승 결속**으로 묶이고, 별도 Run 최종 Boss에 들어가기 위한 선행 조건과 최종 준비의 근거가 됩니다.
- `닌자소울`은 Run 밖 지부 전승 복구, `유파 흔적`은 Run 안 순회·빌드·최종전 준비로 역할을 분리합니다.
### 각 유파의 적 생태계
- 각 유파 전장에는 해당 유파의 철학이 잠식·왜곡된 **전용 몬스터, Elite, Boss, 전장 기믹**이 존재합니다.
- 이 적들은 유파 조직 전체가 악하다는 뜻이 아닙니다. `잠식된 닌자`, `왜곡된 식신`, `유파가 다루던 요괴/전승의 잔재`, `금기에 오염된 수련자`를 섞어 구성합니다.
- 봉마 전장: 소환·결계·봉인으로 공간을 장악하는 위협.
- 천술 전장: 원소 상태와 반응으로 지형/안전 공간을 바꾸는 위협.
- 귀인 전장: 근접 압박과 귀혈 상승으로 오래 붙을수록 강해지는 위협.
- 흑영 전장: 표식·재배치·예고 처형으로 결정적인 한 번을 노리는 위협.
### 후반 Stage의 세계관/기믹 상승
- 같은 유파 전장이라도 몇 번째로 방문했는지에 따라 난세의 잠식 강도가 더 깊게 드러납니다.
- Stage 1은 유파의 기본 흔적과 전투 문법, Stage 2는 상호작용 기믹, Stage 3는 유파 기믹끼리의 연계, Stage 4는 잠식된 전승의 숙련형/복합형 표현을 사용합니다.
- 후반 Stage에서 완전히 새로운 세계 규칙을 갑자기 추가하기보다 **앞에서 본 유파 규칙이 더 깊게 연결되는 느낌**을 우선합니다.
- 특정 유파를 고르면 해당 유파 적이 약해지거나 강해지는 상성 하드카운터를 기본 설정으로 두지 않습니다.
## DEC-2026-08-20-018 · 요기 과포화 + 4유파 내분이 만든 최종재앙 · APPROVED
- 최종재앙은 특정 흑막이 완성품으로 소환한 괴물이 아니라 **4유파의 내분·경쟁적 금기술 사용·봉인/요맥 붕괴·요기 과포화가 누적되어 탄생한 발생형 재앙**입니다.
- 인과: `전란 → 4유파 협력 붕괴/내분 → 금기술 경쟁 → 봉인·요맥 훼손 → 요기 누출/과포화 → 요괴·원혼·잠식 확산 → 더 큰 불신과 전투 → 4유파 전승 잔향과 요기가 응집 → 재앙핵`.
- 4유파 전체를 악역으로 규정하지 않습니다. 각 유파의 철학 자체가 문제가 아니라 **전란 속 일부 세력/개인이 경쟁과 공포 때문에 전승을 왜곡하고 금기를 남용한 것**이 핵심입니다.
- 공동 변방 전선 지부는 과거 4유파 협력의 상징이었고, 플레이어의 4유파 순회는 **협력 실패의 흔적을 되짚고 왜곡된 전승을 회수·안정화하는 과정**으로 읽힙니다.
- `요기`는 요괴·원혼·잠식 현상을 가능하게 하는 초자연적 에너지/오염의 총칭이며, 평소 봉인·요맥·결계가 억제/순환시키던 것이 전쟁과 금기술 충돌로 과도하게 쌓여 넘쳐난 상태가 `요기 과포화`입니다.
- 요기 과포화는 환경·생물뿐 아니라 인법·기억·전승까지 왜곡시켜 각 유파 전장의 전용 Monster/Elite/Boss/기믹 차이를 설명합니다.
### 4유파 흔적과 최종재앙의 대비
- 최종재앙 = **네 전승이 충돌·왜곡된 상태**.
- 플레이어의 4유파 흔적 = **네 전승을 이해·회수·안정화한 상태**.
- 네 흔적은 마지막 휴식에서 모두 결속되지만 한 유파 면모를 자동 강화하지 않습니다. 결속은 4유파 동맹 지원과 Final Boss 진입을 확정하고, 플레이어는 기존 아이템·배치·조합을 사용하는 최종 결속 Workbench에서 자기 빌드를 완성합니다.
- 흔적은 최종보스 기믹을 삭제하는 면역 열쇠가 아니라 플레이어 빌드 철학을 마지막으로 강화하는 준비입니다.
### 최종보스 Working Concept · 난세 재앙핵

- **Phase 3 · 요기 폭주:** 4유파 복사전이 아니라 요맥 균열·요기 분출·재앙핵 파동 같은 **요기 과포화 자체의 고유 패턴**이 중심이 됩니다.

## DEC-2026-08-20-019/020 · 전승 사용 자유 + 4유파 재결속
- 유파 흔적은 `그 유파를 반드시 받아들여야 하는 강화`가 아니라 **그 유파의 전승을 다시 사용할 수 있게 되었다는 증거**입니다. 플레이어는 기존 자기 유파를 더 밀 수도 있고, 해방한 유파의 인법/장비를 백팩에 섞을 수도 있습니다.
- 그래서 4유파를 평정하는 것은 플레이어를 4유파 혼합형으로 강제하는 과정이 아니라 **끊어진 전승의 선택권을 되찾는 과정**입니다.
- 각 유파 Boss/대표는 패배 후 죽어 사라지는 존재보다 잠식과 내분에서 해방되는 인물/수호자/전승자 해석을 우선합니다.
- 마지막 `난세 재앙핵` 전투에서 네 유파가 각자 한 번씩 플레이어를 돕습니다. 이는 과거 내분과 반대로 **4유파가 다시 한 전선에 서는 장면**입니다.
- 지원 순서는 기본적으로 플레이어가 유파를 평정한 순서를 반영하지만, 특정 순서가 정답이 되지 않도록 전투가치는 정규화합니다.
- 네 유파의 지원은 승리를 대신하지 않습니다. 각자 짧게 전장을 열어주고, 마지막 평정과 결정타는 플레이어가 완성한 백팩 빌드가 담당합니다.
## DEC-2026-08-20-021A/022 · 전승 접근과 최종 결속의 의미 · APPROVED
- 유파 흔적은 죽은 영혼이나 자동 전투 버프가 아니라 **해방한 유파의 전승에 다시 접근할 수 있다는 증거**입니다.
- 해당 전승을 실제로 사용할지는 플레이어가 기존 인법·장비를 획득해 백팩에 채용하는지에 달려 있습니다.
- 시작 유파를 끝까지 심화해도 되고, 해방한 다른 유파를 섞어도 되며, 여러 전승을 조합해도 됩니다.
- 네 흔적의 결속은 하나의 유파를 선택해 다른 전승을 버리는 의식이 아닙니다. **네 전승이 모두 다시 연결됐음을 확정하는 지부의 마지막 재정비**입니다.
- 4유파 대표들은 최종 결속 Workbench에서 평정 순서대로 `지원 준비 완료` 상태가 되며, 난세 재앙핵 전투에서 각 1회 길을 엽니다.
- 그러나 최종 승리는 동맹의 합동기나 자동 각성으로 얻지 않습니다. 플레이어가 20분 동안 선택해 완성한 백팩 빌드가 실제 평정을 수행합니다.
```plain text
내분으로 갈라진 4유파
→ 플레이어가 각 전장을 평정
→ 흔적/전승 접근권 복구
→ 공동 지부에서 네 전승 결속
→ 4유파가 다시 한 전선에 섬
→ 각 유파가 한 번씩 길을 엶
→ 플레이어가 자기 방식의 닌자 빌드로 난세 재앙핵을 평정
```
- 이 구조에서 「닌자의 신」은 네 유파 기술을 자동으로 모두 얻은 자가 아니라, **갈라진 전승을 다시 잇고 그 힘을 자기 방식으로 사용해 난세를 평정한 자에게 후대가 붙이는 이름**입니다.
## DEC-2026-08-20-024 · 전장에서 되찾는 유파 흔적
<callout icon="📜" color="purple_bg">
	유파 흔적은 메뉴에서 자동 체크되는 열쇠가 아니라, **잠식된 유파 Elite를 제압한 뒤 전장에 드러나는 전승의 잔향**입니다. 플레이어가 이를 몸으로 받아들여야 해당 유파 Boss가 모습을 드러냅니다.
</callout>
- Elite는 해당 유파의 전승을 붙잡고 있거나 잠식 속에서 왜곡해 사용하는 전장 수문장입니다.
- Elite를 쓰러뜨리면 상자 토큰과 별개로 유파의 문양·술식·의지가 응축된 흔적이 나타납니다.
- 흔적은 플레이어에게 다가와 근접 자동 흡수되며, 별도 의식 버튼이나 제단 점유를 요구하지 않습니다.
- 이 순간은 해당 유파의 힘을 즉시 얻는 장면이 아니라 **잃어버린 전승의 위치와 본질을 되찾는 장면**입니다.
- 흔적을 회수하면 잠식 속에 숨어 있던 유파 Boss의 기척과 길이 드러나고, 전장은 이미 배운 유파 기믹을 Boss 예고형으로 고조시킵니다.
- Boss를 격파하기 전 흔적은 불안정한 `RECOVERED` 상태입니다. Boss 평정 후 공동 지부로 돌아와야 `STABILIZED`되어 전승 접근권이 복구됩니다.
- 따라서 `흔적 회수 = 기술 즉시 장착`이 아니며, 실제 사용 여부는 이후 Boss Reward·Shop·Chest에서 해당 유파 인법/장비를 얻어 백팩에 배치하는 플레이어 선택으로 남습니다.
- 네 유파를 모두 같은 방식으로 정화하지만 흔적의 실루엣·문양·흡수음은 유파별로 달라야 합니다. 색상만으로 구분하지 않습니다.
### 감정 흐름
```plain text
유파의 적·기믹을 견딘다
→ 유파 Elite를 제압한다
→ 전승의 흔적이 모습을 드러낸다
→ 흔적을 받아들인다
→ 유파 Boss의 길이 열린다
→ Boss를 평정한다
→ 지부에서 전승을 안정화한다
→ 그 힘을 백팩에 섞을지 말지는 플레이어가 결정한다
```
### 보호
- 흔적은 죽은 닌자의 실제 영혼을 소비하는 자원이 아닙니다.
- 흔적 자체가 Boss를 약화시키거나 플레이어를 자동 강화하지 않습니다.
- 상자 토큰과 흔적을 같은 서사 보상으로 합치지 않습니다.
- 흔적을 늦게 회수해 일반 적을 무한 사냥하는 행위가 이득이 되지 않도록 Recovery Window 동안 신규 공세는 멈춥니다.
