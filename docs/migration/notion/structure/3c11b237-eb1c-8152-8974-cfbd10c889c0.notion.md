### DEC-027 · 천술류 공간 유도형 자동 반응 · APPROVED / 구현 보류
- 천술류의 기본 `WET → SHOCK` 자동전투는 유지합니다.
- 플레이어는 직접 주문을 조준·순서입력하지 않습니다. 대신 이동으로 적을 모아 **읽을 수 있는 공간 조건**을 만들고, 그 조건 안의 준비된 군집에 다음 자동 반응이 우선적으로 큰 연쇄 결과를 내게 합니다.
- 따라서 천술류의 대표 경험은 `안전선 선택 → 군집 형성 → 청색 준비 → 호박/주황 연쇄 → 궁극기 결산`입니다.
- 직접 발동형 반응은 입력·터치·게임패드 부담 때문에 첫 Slice에서 기각했고, 완전 자동 타기팅만으로 끝나는 현재 형태도 최종 Player Promise로 채택하지 않습니다.
- 구체 형태는 DEC-028의 **자동 ****`WET`**** 시전 지점에 짧게 남는 고정 청색 준비 결계**로 확정했습니다. 다음 자동 `SHOCK`은 그 안의 준비된 `WET` 군집을 우선해 고가치 호박/주황 연쇄를 냅니다.
- 아직 미결정: 지속시간/반경/군집 임계값/수치, Elite·Boss 변주. 현재 런타임의 자동 타기팅과 기존 화염 시각 효과는 이 제품 의도를 이미 구현했다는 증거가 아닙니다.
- 구현은 나머지 Phase 1 결정과 단일 구현계약 검토 뒤 별도 패키지로 진행합니다.

- 작은 상태 아이콘, 피격된 적 하나만 보이는 HP 바, 청색 + 호박/주황 색 문법을 함께 유지합니다.

### DEC-032 · 선택형 확장 유파 도움말 · APPROVED / 구현 보류
- 첫 `0:00–0:30`에 강제 prompt·설명 카드·행동 마커를 넣지 않습니다. 플레이어가 원할 때만 현재 선택 유파의 기존 전투 `기능 도움말`에서 더 명확한 한국어 설명을 확인합니다.

- 상태는 계속 작은 아이콘으로 보이며, 도움말은 선택형 설명/접근성 경로일 뿐 전장 위 지속 상태 텍스트가 아닙니다.

### DEC-010 · 5회 적대적 검토
**Loop 1 · 첫인상/가독성**
- PASS 조건: 첫 30초 안에 네 유파의 위험 처리 방식이 다르게 느껴져야 함.
- 발견: 현재 이름/기술만 보면 봉마·천술은 둘 다 광역 제어, 귀인·흑영은 둘 다 폭딜로 오해 가능.
- 수정: `지속 장악 / 반응 연쇄 / 근접 지속 / 우선 처형`을 각각 주동사로 고정.
**Loop 2 · 자동전투 조작 충돌**
- 발견 1: 봉마류가 고정 포탑/진지에 머무르도록 강요하면 서바이버 이동 재미와 충돌.
- 수정: 식신·결계·설치물은 플레이어의 이동 동선을 따라 재배치되거나 짧은 주기로 새 위치에 형성되는 **이동형 진지**를 우선. 기지방어식 정지 플레이는 금지.
- 발견 2: 흑영류가 마우스로 표적을 직접 고르게 하면 현재 `이동 + 보법/오의 수동, 기본 공격/전투 인법 자동` 원칙과 충돌.
- 수정: 표식은 공격/거리/엘리트 우선 규칙으로 자동 부여하고, 플레이어는 **위치 선정과 빌드**로 어떤 적이 먼저 처형될지 간접 제어.
**Loop 3 · 불공정 위험/보상**
- 발견: 귀인류를 `저체력일수록 강함` 하나로 고정하면 다수 적 탄막에서 의도치 않은 피격이 빌드를 망치고 초보자에게 불공정할 수 있음.
- 수정: 핵심 위험은 낮은 HP 자체가 아니라 **적 근처에 오래 머무는 것**. 귀혈/광전은 근접 처치·근접 체류·피격 후 회복 같은 복수 경로로 쌓고, 임계 저체력은 선택 빌드로 한정.
**Loop 4 · 백팩 시스템 결속**
- 발견: 유파 차이가 전투 스킬에만 있으면 핵심 백팩이 공통 정답으로 수렴할 위험.
- 수정: 새 공간 알고리즘을 만들지 않고 기존 직교 인접·태그 시너지 안에서 유파별 `좋은 짝`을 다르게 설계.
	- 봉마: 소환 + 설치/결계
	- 천술: 서로 다른 원소/상태 조합
	- 귀인: 근접 무기 + 생존/회복
	- 흑영: 원거리/투척 + 표식/독/처형
**Loop 5 · 제작비/장기 확장성**
- 발견: 유파마다 완전 독립 자원 UI·전용 공간 규칙·전용 조작을 만들면 MVP가 4개 게임으로 분열.
- 수정: 고유 축은 기존 `영력 / 오행순환 / 귀혈 / 암영표식`을 **얕은 1개 앵커**로만 사용. 공통 전투/백팩/Workbench/Fate 프레임은 공유.
- 장기 확장은 각 유파의 스킬·조합·아이템 풀로 넓히며, 새 전용 시스템은 플레이테스트에서 기존 앵커만으로 차별성이 부족할 때만 추가.
**5회 결과 / 승인:** **A+얕은 고유 앵커**로 확정했습니다. 현재 조작·백팩·1인 제작 범위와 가장 잘 맞으며, 구현은 `기획 완료` 이후 별도 단계에서 진행합니다.

## DEC-2026-08-20-016 · 유파 흔적 = Run 전승 잔향 + 최종 결속 · APPROVED
- 유파 흔적은 닌자소울과 다른 **Run 전용 전승 자원**입니다. 닌자소울은 Run 밖 지부 복구, 흔적은 Run 안 경로·빌드·최종전 준비를 담당합니다.
- 각 유파 전장에서 전장 후반에 해당 유파 흔적을 회수하고, 흔적 회수로 해당 유파 Boss 접근/출현 조건을 충족합니다.
- Boss 격파 후 지부 귀환 시 흔적이 안정화되어 남은 Run 동안 `작은 범용 효용 + 해당 유파 태그/철학 강화` 효과를 제공합니다. 정확한 수치는 후속 밸런스 값입니다.
- 봉마 흔적: 소환·설치·결계·지속효과 방향.
- 천술 흔적: 상태·원소·반응 방향.
- 귀인 흔적: 근접·생존·위험 유지 방향.
- 흑영 흔적: 원거리·투척·치명·우선처형 방향.
- 4번째 유파 Boss 이후 네 흔적은 마지막 휴식에서 **최종 전승 결속**으로 합쳐집니다. 과거의 `한 전승 면모를 자동 강화하는 최종 준비 선택`은 DEC-022로 폐기했습니다. 네 전승은 모두 결속 상태와 동맹 지원 준비로 유지하고, 최종 전투력은 기존 19종 아이템·3조합을 사용하는 최종 결속 Workbench에서 완성합니다.
