# 닌자의 신 · 제1 공세 Encounter / Elite / Boss 기획

상태: `PLANNING_ACTIVE / DEC-012_PENDING_USER_APPROVAL`
기준 branch: `docs/world-core-planning-20260820`
선행 owner: `docs/planning/2026-08-20-four-schools-signature-planning.md`

제품 코드·Scene·Resource·runtime은 현재 범위가 아니다. 이 문서는 DEC-011에서 승인된 `시작 즉시 시그니처 → 3분 엘리트 → 5분 보스 결산`을 실제 공세 Encounter 문법으로 내리는 기획 owner다.

## DEC-PENDING-WORLD-012 · 공통 위협 세트 + 다중 해법

### A · 하나의 공통 Encounter 문법을 4유파가 다르게 해결 · **권장**

유파별 전용 적/엘리트/보스를 만들지 않는다. 제1 공세는 동일한 적 역할 세트와 동일한 엘리트/보스를 공유하되, 각 유파의 위험 처리 철학이 서로 다른 해법을 만든다.

#### MVP/Vertical Slice 적 역할 최소 세트

1. **추격 잡병 / 잠식 닌자 · Swarm**
   - 현재 `EnemyChaser`를 직접 재사용할 수 있는 기본 압박 역할.
   - 수가 늘어날수록 이동 경로를 좁히고, 천술의 반응 연쇄·귀인의 근접 귀혈·봉마의 지속 장악에는 재료가 된다.
   - 흑영에게는 핵심 표적에 표식이 분산될 수 있는 전장 노이즈가 된다.

2. **금기술 사수/주술사 · Priority Threat**
   - 일정 거리를 유지하거나 멈춰서 **명확한 선/원형 예고 후 원거리 공격**을 수행하는 역할.
   - 반드시 먼저 죽여야 하는 하드 규칙은 아니지만 오래 방치할수록 안전 공간을 줄인다.
   - 흑영의 `우선 처형`, 봉마의 위치 재형성, 천술의 잡몹을 이용한 연쇄, 귀인의 위험한 접근/이탈 판단을 동시에 시험한다.

3. **잠식 중장/대형 요괴 · Anchor**
   - 느리고 체력이 높으며 가까이 붙으면 강한 접촉/압박을 주는 역할.
   - 단순 스펀지가 아니라 전장을 점유해 플레이어의 이동 동선을 바꾼다.
   - 봉마는 시간을 벌며 소환 전력을 누적하고, 천술은 주변 잡몹과 상태를 연결하고, 귀인은 붙어서 자원을 유지할 기회와 위험을 동시에 얻고, 흑영은 표식 집중 여부를 판단한다.

첫 Vertical Slice에서는 **이 3역할 + 엘리트 + 보스**를 상한으로 보고, 비행/치유/방어막/텔레포트 등 추가 적 역할은 플레이테스트에서 전투 읽기나 빌드 검증이 부족할 때만 늘린다.

### 약 3분 엘리트 · `공세 선봉대장` 역할

최종 이름/아트는 후속 Visual/World 작업에서 정한다. 기능은 다음처럼 제한한다.

- 기본적으로 플레이어를 압박하는 강한 근접/돌진형 엘리트.
- **명확히 예고되는 돌진 또는 부채꼴/선형 공격** 하나.
- 일정 주기마다 소수의 추격 잡병을 전장에 추가하는 **증원 호출** 하나.
- 상태/표식/소환 피해에 대한 유파별 면역을 두지 않는다.
- 억지 퍼즐 실드나 특정 속성 필수 파훼를 넣지 않는다.

유파별 시험:

| 유파 | 같은 엘리트를 보는 판단 |
|---|---|
| 봉마 | 증원은 식신/결계에 맡기면서 돌진에 맞춰 전선을 재형성할 수 있는가 |
| 천술 | 증원 잡병을 반응 전파 매개로 써 엘리트 주변 압력을 함께 낮출 수 있는가 |
| 귀인 | 엘리트 가까이 붙어 귀혈을 유지하되 큰 예고 공격에는 빠질 수 있는가 |
| 흑영 | 잡병 노이즈 속에서도 엘리트를 우선 위협으로 읽고 표식/처형을 집중할 수 있는가 |

엘리트 처치 보상은 기존 승인대로 **상자 토큰**과 연결한다.

### 약 5분 보스 · `잠식된 공세대장` 역할

최종 이름/캐릭터는 고정하지 않는다. 세계관 기능은 **인간 전란에서 금기의 힘을 사용한 적대 닌자/지휘관이 잠식까지 일으킨 복합 위협**을 첫 5분 안에 보여주는 것이다.

#### 보스 공통 문법

- **단일 핵심 표적**: 유파 정체성을 비교하기 위한 공통 기준점.
- **증원 압박**: 일정 주기 소수 잡병을 호출하여 광역/지속 장악과 단일 처형 모두 의미가 있게 함.
- **큰 예고 공격 1종**: 돌진/내리찍기/금기술 선형 폭발 중 하나. 이동으로 피할 수 있고, 무적/특정 스킬을 강요하지 않음.
- **잠식 고조 1단계**: 체력 임계점 이후 공격/증원 템포 또는 위험 영역이 증가해 오의 사용 타이밍을 만든다.
- 상태 이상/표식/소환에 대한 전면 면역은 사용하지 않는다. 필요하면 보스용 수치 감쇠를 쓰더라도 유파 핵심 루프가 무효화되지 않게 한다.

유파별 결산:

- 봉마: 보스와 증원 사이에서 소환 전력이 무너지지 않게 유지하다 백귀야행으로 전선을 밀어낸다.
- 천술: 증원에 붙인 상태를 보스 주변 반응으로 연결하고 오행폭주로 누적 상태를 결산한다.
- 귀인: 보스 근접 위험을 감수해 귀혈을 유지하고 큰 예고 공격 때만 이탈한 뒤 귀인화로 재진입한다.
- 흑영: 증원 노이즈 속 핵심 위협에 표식을 집중하고 암영처형으로 보스/우선 표적을 결산한다.

### 시간 배치 초안

정확한 초 단위는 후속 cadence Decision에서 확정한다.

```text
0:00~0:30  추격 잡병 중심 · 유파 기본 동사 학습
0:30~1:30  Priority Threat 첫 등장 · 위치/우선순위 학습
1:30~2:50  Swarm + Anchor/Threat 혼합 · 빌드 철학 반복
약 3:00    공세 선봉대장 Elite
Elite 이후  혼합 압박 상승 / 오의 준비
약 5분권   잠식된 공세대장 Boss
Boss 처치   RESULT → 보스 보상 → Workbench → Fate
```

### B · 유파별 전용 엘리트/보스 4세트

- 각 유파의 강점을 정밀하게 가르칠 수 있다.
- 그러나 적/AI/아트/테스트/밸런스가 4배 가까이 늘고, 플레이어가 유파를 바꿀 때 `같은 공세를 다른 방식으로 해결한다`는 비교가 사라진다.
- 특정 유파 전용 튜토리얼 콘텐츠처럼 보일 위험이 있어 첫 Vertical Slice에는 비채택 권장.

### C · 선택 유파에 따라 Director가 적 조합을 자동 변경

- 봉마 선택 시 광역 압박, 흑영 선택 시 정예 비중 증가 등 유파별 맞춤 시험이 가능하다.
- 하지만 게임이 플레이어 빌드에 맞춰 몰래 난이도를 조정한다는 느낌, 유파별 밸런스 분기, 디버깅/재현성 비용이 커진다.
- 장기 Challenge Director 후보로는 남길 수 있으나 첫 제품 코어에는 비채택 권장.

## 5회 적대적 검토

### Loop 1 · 유파 공정성

문제: 공통 적 세트가 실제로는 특정 유파에만 쉬울 수 있다.

수정:
- 상태/표식/소환을 봉쇄하는 유파 하드카운터 면역 금지.
- 모든 큰 공격은 이동으로 피할 수 있는 공통 대응을 제공.
- 잡몹은 광역 유파의 먹이가 되면서 동시에 흑영의 표식 분산 노이즈가 되도록 하되, 흑영이 엘리트/위협을 자동 우선할 조정 후보를 함께 유지.

### Loop 2 · 모든 유파가 결국 DPS 레이스가 되는 위험

문제: 적이 체력/속도만 다르면 4유파 모두 `더 세게 때린다`로 수렴한다.

수정:
- 적 역할을 `Swarm / Priority Threat / Anchor`로 분리.
- 엘리트/보스에는 증원 + 큰 예고 공격을 넣어 `장악 / 연쇄 / 근접 유지 / 우선 처형` 판단을 동시에 발생시킨다.

### Loop 3 · 첫 30초 과부하

문제: 시작부터 세 적 역할을 모두 던지면 유파 자체를 배우기 전에 전투 문법을 학습해야 한다.

수정:
- 0~30초는 기본 추격병 중심.
- Priority Threat는 기본 동사를 본 뒤 투입.
- Anchor 혼합은 1분 이후로 미룬다.

### Loop 4 · 자동전투 타게팅 충돌

문제:
- 현재 흑영은 가까운 적 최대 3명을 공격해 `위험한 대상 우선 처형`과 충돌 가능.
- 귀인은 근접에 들어가야 하므로 원거리 적이 지나치게 도망가면 불공정.

수정:
- Priority Threat는 무한 카이팅 대신 공격 준비 중 정지/감속하는 명확한 접근 창을 둔다.
- 구현 단계에서 흑영 자동 타게팅에 `elite/threat > distance` 계열의 가중치를 검증 후보로 둔다. 수동 클릭은 추가하지 않는다.

### Loop 5 · 1인 제작비 / 재사용성

문제: 역할마다 전용 AI를 깊게 만들면 계획이 다시 커진다.

수정:
- 첫 Vertical Slice 상한을 기본 3역할 + 엘리트 + 보스 1종으로 고정.
- 가능한 한 현재 `EnemyChaser`의 이동/HP/접촉 피해 계약을 공통 기반으로 재사용하고, 새 행동은 예고 공격/거리 유지/증원처럼 작은 조합형 컴포넌트로 설계하는 방향을 우선한다.
- 유파별 전용 보스 4종, 다단 퍼즐 실드, 상성 면역, 복잡한 페이즈 스크립트는 제외.

## 현행 runtime 차이 · 구현 전 MUST_RECONCILE

- 현재 `WaveSpawner`는 기본 EnemyChaser 한 종류만 생성한다.
- 현재 `StageBoss`는 티어별 HP/속도/접촉 피해만 다르고 전용 기믹이 없다.
- 현재 `StageFlowController`는 `segment_duration_seconds = 300` 종료 후 Boss를 요청하고 총 3세그먼트에서 COMPLETE 처리한다.
- 최신 승인 기획은 `약 20분 / 4×5분`이다. 따라서 **3→4 세그먼트와 `5분 보스`가 보스 등장 시점인지 결산 목표 시점인지**는 구현 전에 별도 cadence 결정으로 명시적으로 화해해야 한다.

## 벤치마크 원리

- Hades: 같은 Run 환경에서 다양한 적/미니보스 위험과 무기/Boons 조합이 함께 늘어나며, 다른 빌드가 같은 위험을 다른 방식으로 처리하는 원리를 참고한다.
- Deep Rock Galactic: 적군 구성/특정 파도가 전투의 문제를 바꾸는 역할 기반 Encounter 원리를 참고한다. 협동 역할 구조는 복제하지 않는다.
- Vampire Survivors: 캐릭터를 고르고 공통한 호드 환경을 상대하는 즉시성 및 빌드별 대응 차이 원리를 참고한다.

외부 작품의 적 이름·공격 패턴·보스·맵을 복제하지 않는다.

## 권장 결론

**A · `공통 적 역할 3종 + 공통 3분 엘리트 + 공통 5분 보스, 그리고 네 유파의 서로 다른 해법`**을 DEC-012로 권장한다.

승인 후 다음 Decision은 **DEC-013 · 5분 cadence의 정확한 시간 의미(보스 등장 vs 보스 결산) + 4세그먼트 Run clock**을 잠근다.
