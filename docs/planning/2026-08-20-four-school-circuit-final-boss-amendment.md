### 확정된 Run 상위 구조

플레이어는 무너진 4유파 공동 변방 전선 지부를 출발/귀환 허브로 사용한다. 전투가 20분 내내 지부 주변에서만 이어지는 구조가 아니다.

```text
무너진 공동 지부 / 유파 선택
→ 유파 전장 A 이동
   → 약 5분 전투
   → 해당 유파의 흔적 회수
   → 해당 유파 기술/특징을 지닌 유파 보스 격파
   → RESULT / 보상
   → 공동 지부 귀환 / Workbench / Fate
→ 유파 전장 B 이동
   → 약 5분 전투
   → 흔적 회수
   → 해당 유파 보스 격파
   → RESULT / 보상
   → 공동 지부 귀환 / Workbench / Fate
→ 유파 전장 C 이동
   → 약 5분 전투
   → 흔적 회수
   → 해당 유파 보스 격파
   → RESULT / 보상
   → 공동 지부 귀환 / Workbench / Fate
→ 유파 전장 D 이동
   → 약 5분 전투
   → 흔적 회수
   → 해당 유파 보스 격파
→ 약 20분 · 4유파 순회 완료
→ RESULT / 보상
→ 공동 지부 최종 휴식 / Workbench / Fate
→ 별도 최종보스전
→ 최종 결과 / 닌자소울 / 전설
```

### 4유파 보스 원칙

- 봉마류 전장에서는 **봉마류의 흔적, 기술, 전투 철학**을 지닌 보스를 상대한다.
- 천술류 전장에서는 **천술류의 흔적, 기술, 전투 철학**을 지닌 보스를 상대한다.
- 귀인류 전장에서는 **귀인류의 흔적, 기술, 전투 철학**을 지닌 보스를 상대한다.
- 흑영류 전장에서는 **흑영류의 흔적, 기술, 전투 철학**을 지닌 보스를 상대한다.
- 이 네 보스의 정체성은 플레이어가 시작할 때 선택한 유파가 아니라 **현재 방문 중인 유파 전장**이 결정한다.
- 따라서 플레이어가 봉마류를 선택해도 천술류 전장에서는 천술 계열 보스, 귀인류 전장에서는 귀인 계열 보스를 만난다.
- 특정 유파 전체를 악역으로 규정하지 않는다. 보스는 전란·금기·잠식으로 왜곡된 해당 유파의 개인/전승/흔적일 수 있다.
- 각 보스는 해당 유파의 철학을 읽고 대응하게 하지만, 특정 유파가 아니면 공략할 수 없는 하드카운터/면역 퍼즐은 만들지 않는다.

### 흔적 회수 원칙

- 각 5분 유파 전장에서 해당 유파의 **흔적**을 회수한다.
- 흔적은 단순 전리품이 아니라 4유파 순회와 최종보스 이전 진행을 연결하는 핵심 Run 맥락이다.
- 다만 흔적의 정확한 정체(전승 조각/봉인 조각/기술 기록/영적 잔향 등), 획득 타이밍의 세부 규칙, 최종보스에서의 실제 기능은 아직 확정하지 않는다.
- 현재 확정 범위는 `각 유파 전장에서 흔적을 회수한다`와 `4유파 순회가 최종보스 이전의 필수 진행이다`까지다.

### DEC-006 보정 · 공동 지부의 역할

기존 `무너진 지부 중심 생존/반격`의 감정적 출발점은 유지한다. 다만 공간 해석을 다음처럼 보정한다.

- 공동 지부 = Run 시작점, 생존의 이유, Workbench/메타 복구, 전장 사이 귀환 허브.
- 4개의 주요 5분 전투 = 각 유파의 전장/지부/유적/흔적 지역으로 이동해 수행.
- 따라서 `같은 지부 주변 공간을 4단계로 확장`하는 해석은 폐기한다.

### DEC-012 보정 · 선택 유파 거울상 → 방문 유파 보스

- 과거 DEC-012의 `제1 공세 보스 = 선택 플레이어 유파의 거울상` 해석은 폐기한다.
- 최신 구조에서는 **각 유파를 하나씩 방문하고 그 유파의 보스를 하나씩 상대**한다.
- 공통 보스 프레임/예고 공격/보상/사망 처리 같은 재사용 가능한 기술적 골격은 유지할 수 있지만, 네 유파 보스의 패턴과 시각 언어는 각 유파 특징을 분명히 보여야 한다.

### DEC-013 보정 · 20분의 의미

- `4×5분` active-combat 목표는 유지한다.
- 각 유파 구간은 5분대 보스 결산을 목표로 하며 5:00은 hard fail이 아니고 필요하면 soft overtime을 허용한다.
- **약 20분은 4번째 유파 보스를 처리해 4유파 순회를 완료하는 목표 시점**이다.
- 약 20분 뒤 공동 지부로 귀환해 최종 Workbench/Fate 휴식을 진행한다.
- **Run 최종보스는 이 20분 순회 이후의 별도 전투**이며 20분 active-combat 예산에 포함한다고 간주하지 않는다.
- 따라서 최종 제품의 실제 wall-clock Run 길이와 최종보스 전투 시간은 별도 결정/플레이테스트로 확정한다.

### 기존 3분 Elite와의 관계

- 각 5분 유파 전장 안의 약 3분 Elite cadence는 현재 승인 상태를 유지한다.
- Elite는 해당 유파 전장의 분위기/위협을 예고할 수 있으나, 반드시 유파 보스의 축소판일 필요는 없다.
- 첫 Vertical Slice 제작비를 지키기 위해 공통 Elite 프레임을 재사용할 수 있다.

### 제작비 보호

- 유파 전장 4개가 완전히 다른 게임 규칙이 되지 않는다.
- 공통 전투/적 역할/Elite/보상/Workbench/Fate 프레임은 재사용한다.
- 차이는 전장 비주얼·적 조합 가중치·유파 흔적·유파 보스 패턴/연출에 집중한다.
- 각 유파 전장마다 전용 조작법, 전용 UI, 전용 경제, 전용 백팩 규칙을 만들지 않는다.

### 아직 확정하지 않은 것

1. 4유파 방문 순서가 고정인지, 플레이어가 다음 유파를 선택하는지.
2. 플레이어가 선택한 시작 유파를 먼저 방문하는지 여부.
3. 각 유파 흔적의 정확한 세계관 정체와 최종보스에서의 기능.
4. 20분 뒤 별도 최종보스전의 목표 전투 시간/페이즈 수.
5. 최종보스가 네 흔적을 어떻게 반영하는지.

## DEC-014 최종 한 줄

**`무너진 공동 지부를 허브로 삼아 5분마다 4유파의 전장으로 이동하고, 각 유파의 흔적을 회수한 뒤 그 유파 기술/특징을 지닌 보스를 하나씩 격파한다. 4번째 유파 보스를 약 20분에 처리한 뒤 공동 지부에서 마지막으로 정비하고, 그 후 별도 Run 최종보스를 상대한다.`**
