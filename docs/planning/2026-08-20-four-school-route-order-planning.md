## DEC-PENDING-WORLD-015 · 4유파 방문 순서

DEC-014로 모든 Run은 봉마·천술·귀인·흑영 4유파 전장을 모두 한 번씩 방문하고, 각 전장에서 흔적을 회수한 뒤 해당 유파 보스를 상대하는 구조로 확정됐다. 남은 결정은 네 전장의 **순서**다.

### A · 모든 플레이어에게 완전 고정 순서

예: 봉마 → 천술 → 귀인 → 흑영.

장점:
- 난이도/보상/서사 pacing을 가장 정밀하게 고정 가능.
- 첫 Vertical Slice 테스트 경우의 수가 가장 적음.

문제:
- 시작 때 고른 플레이어 유파와 첫 전장이 무관할 수 있다.
- 유파 선택 직후 자기 유파의 철학을 적의 형태로 읽는 DEC-010/011 학습 연결이 약해질 수 있다.

### B · 선택한 플레이어 유파를 첫 전장으로, 이후는 canonical ring 순환 · 권장

기본 ring 예시:

```text
봉마 → 천술 → 귀인 → 흑영 → (봉마)
```

플레이어가 선택한 유파가 ring의 시작점이 된다.

```text
봉마 선택: 봉마 → 천술 → 귀인 → 흑영
천술 선택: 천술 → 귀인 → 흑영 → 봉마
귀인 선택: 귀인 → 흑영 → 봉마 → 천술
흑영 선택: 흑영 → 봉마 → 천술 → 귀인
```

장점:
- 첫 5분에 `내가 고른 유파`와 `그 유파의 흔적/보스`를 맞붙여 플레이어 철학을 가장 빠르게 각인한다.
- 이후 다른 세 유파를 모두 경험하므로 세계가 선택 유파 하나에만 종속되지 않는다.
- 전체 순열 24개가 아니라 4개 회전만 테스트하면 된다.
- 4유파 콘텐츠는 모두 매 Run 등장하므로 콘텐츠 누락이 없다.

주의:
- 첫 유파 보스가 플레이어와 같은 유파의 하드카운터가 되면 안 된다. `같은 철학을 적의 편에서 읽는 시험`이어야 한다.
- ring의 정확한 유파 순서는 세계관/비주얼 pacing을 보면서 후속 tuning 가능하며, 핵심 결정은 `선택 유파 first + 나머지 고정 순환`이다.

### C · 각 휴식에서 다음 유파를 자유 선택

장점:
- 현재 빌드에 따라 다음 보스/보상/흔적을 선택하는 강한 전략성.
- 반복 Run의 route variation이 커짐.

문제:
- 최대 24개 방문 순서 조합을 고려해야 함.
- 모든 유파 전장/보스가 1~4번째 어느 위치에서도 난이도·보상·튜토리얼 역할을 수행해야 함.
- 첫 Vertical Slice에서 플레이어가 아직 다른 유파 전장을 모르는 상태라 선택이 정보 없는 선택이 될 수 있음.
- 밸런스/QA/서사 조건 수가 크게 증가.

장기 후보로 보존한다.

## 적대적 검토

1. **첫 5분 정체성:** A는 선택 유파와 첫 전장이 어긋날 수 있음 → B가 가장 강함.
2. **반복성:** B는 4개 회전뿐이라 반복성이 낮을 수 있음 → 추후 route choice/변형 모드로 C를 해금 후보로 보존.
3. **난이도:** 같은 유파가 항상 1번째라 선택 유파마다 상대적으로 쉬운 보스가 달라짐 → 각 학교 보스의 기본 강도 예산을 맞추고 segment scaling을 공통화.
4. **세계관:** 자기 유파 보스를 먼저 죽이는 것이 `유파가 악역`처럼 보일 위험 → 보스는 유파 조직 전체가 아니라 전란·금기·잠식으로 왜곡된 개인/전승임을 연출.
5. **제작비:** C의 24순열을 첫 제품부터 검증하지 않음. B는 4회전만 요구해 solo scope에 맞음.

## 장기 재검토 조건

- 4유파 전장/보스가 모두 안정적으로 완성되고 각 전장이 1~4번째 어느 위치에서도 scaling 가능한 것이 검증되면 C의 자유 경로 선택을 재검토한다.
- 플레이테스트에서 고정 순환이 2~3회 만에 강하게 예측 가능/반복적으로 느껴지면 route choice 또는 2개 후보 중 선택하는 절충안을 검토한다.

## 권장 결론

**B · `플레이어가 선택한 유파를 첫 5분 전장으로 사용하고, 나머지 세 유파는 canonical ring의 고정 순환으로 모두 방문`**을 DEC-015로 권장한다.
