## DEC-2026-08-20-010 · 4유파 = 서로 다른 위험 처리 방식

상태: `APPROVED_BY_USER_2026-08-20`

### 승인된 핵심

기존 4유파를 교체하지 않는다. 유파 정체성의 최상위 기준을 `무슨 속성/기술을 쓰는가`보다 **`공세의 위험을 어떤 방식으로 처리하는가`**로 둔다.

| 유파 | 확정 위험 처리 철학 | 얕은 고유 앵커 | 대표 전투 감정 |
|---|---|---|---|
| 봉마류 | **지속 장악** · 공간을 준비하고 대신 싸우게 하며 버틴다 | 영력 | 소환·결계가 누적되어 내가 직접 전부 처리하지 않아도 전선이 버텨짐 |
| 천술류 | **반응 연쇄** · 상태를 만들고 원소 반응으로 전장을 바꾼다 | 오행반응/오행순환 | 적 무리가 상태 → 반응 → 연쇄 피해/제어로 무너짐 |
| 귀인류 | **근접 지속** · 위험한 근접을 유지할수록 강해진다 | 귀혈 | 적 무리 안쪽을 파고들어 압박을 버티면서 힘을 끌어올림 |
| 흑영류 | **우선 처형** · 위험한 대상을 골라 먼저 제거한다 | 암영표식 | 표식이 쌓인 핵심 표적이 폭발/처형되며 전선의 위험도가 급감함 |

### 공통 프레임 보호

- 4유파는 네 개의 독립 게임이 아니다.
- 이동, 자동 전투, 처치 콤보/스타일, 보상 흡수, RESULT, Persistent Workbench, 백팩, 조합, Fate 프레임은 공유한다.
- 유파별로 완전히 별도 조작·전용 공간 알고리즘·대규모 전용 UI를 만들지 않는다.
- `영력 / 오행반응 / 귀혈 / 암영표식`은 각 유파의 **얕은 1개 고유 앵커**로 유지한다.

### 백팩 결속 원칙

새 공간 알고리즘을 추가하지 않고 기존 직교 인접·태그 시너지 안에서 유파별로 선호하는 좋은 짝을 다르게 만든다.

- 봉마류: `소환 + 설치/결계`
- 천술류: `서로 다른 원소/상태 조합`
- 귀인류: `근접 무기 + 생존/회복`
- 흑영류: `원거리/투척 + 표식/독/처형`

### 현재 runtime과의 정합성

기존 MVP-2 구현은 이미 이 방향의 대부분을 갖는다.

- 봉마: 공격형 식신 + 영력 + 주기적 봉인진 + 백귀야행.
- 천술: 화둔·염옥진 + BURN/WET/SHOCK + WET→SHOCK 반응 + 오행폭주.
- 귀인: 혈난무 근접 펄스 + 귀혈 + 귀인화.
- 흑영: 만천화우 다중 원거리 공격 + 암영표식 + MARK BURST + 암영처형.
- 유파 선택 UI의 stable id `bongma / cheonsul / guiin / heukyeong`와 기존 one-shot 선택 구조는 유지한다.

따라서 DEC-010은 MVP-2 runtime을 폐기하는 변경이 아니라, 이미 구현된 대표 감정을 **장기 제품 정체성 규칙으로 승격**하는 결정이다.

### 5회 적대적 검토 결과

1. **첫인상/가독성:** 봉마·천술이 둘 다 광역 제어, 귀인·흑영이 둘 다 폭딜로 읽힐 위험 → 주동사를 `지속 장악 / 반응 연쇄 / 근접 지속 / 우선 처형`으로 고정.
2. **자동전투 충돌:** 봉마의 정지 진지가 이동을 방해할 위험, 흑영의 수동 표적 클릭이 조작 원칙과 충돌할 위험 → 봉마는 장기적으로 이동형/재형성 진지 우선, 흑영 표식은 자동 규칙 + 위치/빌드로 간접 제어.
3. **불공정 위험:** 귀인 핵심을 `HP가 낮을수록 강함` 하나로 고정하면 우발 피격이 필수 전략이 됨 → 핵심은 `근접 체류/근접 적중/처치로 귀혈 유지`; 저체력 광전은 선택 빌드로 격하.
4. **백팩 결속:** 유파 차이가 전투 runtime에만 있으면 백팩이 공통 정답으로 수렴 → 기존 직교 인접/태그 규칙 안에서 유파별 좋은 짝을 다르게 설계.
5. **제작비:** 유파마다 독립 UI·입력·자원체계·공간규칙을 추가하면 MVP가 4개 게임으로 분열 → 공통 프레임 + 얕은 앵커 1개를 보호.

### 현재 구현과 미래 제품 설계 사이의 조정 후보

아래는 **기획상 조정 후보**이며 이번 planning stage에서 runtime을 수정하지 않는다.

- 봉마 runtime의 현재 봉인진은 8초마다 현재 위치에 생성되고 4초 고정된다. 첫 플레이에서 한 지점에 서 있도록 강요하는지 검증하고, 필요하면 짧은 재형성/이동 동선 친화 방식으로 조정한다.
- 귀인 runtime의 현재 광전사 보정은 HP 50% 이하에서 즉시 강화된다. 제품 정체성은 `근접 지속`이 우선이며 저체력 보정은 선택적 보너스가 되도록 후속 설계에서 재검증한다.
- 흑영 runtime은 현재 가까운 적 최대 3명을 우선한다. 제품 목표는 `위험한 대상 우선 처형`이므로, 수동 클릭 없이 엘리트/위협/거리 가중치 등 자동 우선순위를 후속 검증한다.
- 천술의 현재 WET/SHOCK 교대는 MVP용 대표 반응 장치다. 최종 제품에서 화둔 하나가 물/번개를 모두 부여하는 설정으로 고정하지 않는다.

### 성공 기준

- 첫 30초 안에 플레이어가 네 유파의 공격 모양뿐 아니라 **자기가 위험을 다루는 방식**이 다르다고 느낀다.
- 같은 공세에서도 이동 위치, 원하는 보상, 백팩 인접 조합, 오의 사용 기대가 유파마다 달라진다.
- 특정 유파만 안전/범용 정답이 되지 않는다.
- 유파 차이를 이해시키기 위해 별도 장문의 튜토리얼을 요구하지 않는다.

## DEC-PENDING-WORLD-011 · 첫 5분 시그니처 경험 패키지

다음 결정은 각 유파가 **제1 공세 0~5분** 안에 무엇을 반드시 보여줘야 플레이어가 선택의 차이를 이해하는지 확정한다.

비교할 축:

1. `기존 대표 인법을 즉시 사용 + 고유 앵커를 초반에 확실히 체험 + 3분 엘리트/5분 보스에서 정체성 결산`
2. Run 시작 전에 유파별 시작 인법 2~3개 중 선택하게 해 초기 빌드를 넓히는 방식
3. 초반에는 약하게 시작하고 전투 중 드래프트로 유파 정체성을 완성하는 방식

DEC-011은 첫 세션 온보딩, 첫 보스, 시작 선택 화면, 성장 보상, MVP 제작비와 직접 연결되므로 사용자 승인 전 잠그지 않는다.
