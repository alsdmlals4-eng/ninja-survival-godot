## 결론

**암영표식은 대상별 `8.0초 갱신형 지속시간`을 사용한다.**

- 암영표식을 새로 부여하거나 추가 중첩하면 해당 대상의 남은 시간이 현재 유효 지속시간 전체로 갱신된다.
- 지속시간이 끝나면 그 대상의 모든 미폭발 표식과 표식 배지가 함께 제거된다.
- 만료는 피해·폭발·처형을 발생시키지 않는다.
- 적 사망, MARK BURST, 암영처형, runtime 비활성화, Run/Scene 종료에서도 표식은 제거된다.
- 살아 있고 유효한 적에게 남아 있는 표식만 오의 준비 수치에 포함한다.

초기 수치:

```text
기본 지속시간 = 8.0초
오의 비전서 1개 = +25% → 10.0초
오의 비전서 1개 + 봉인의 길 준비 보정 = +55% → 12.4초
```

정확한 계산은 기존 `heukyeong_mark_duration_pct` 가산 채널을 사용한다. 기존 중복 상한과 modifier 합산 규칙을 변경하지 않는다.

## 왜 최초 MVP-2의 무기한 표식이 현재 정본이 아닌가

### 시간순 권한

1. 최초 MVP-2 설계는 표식에 시간 만료가 없다고 기록했다.
2. 후속 MVP-2 수동 조정은 암영처형의 준비 기준을 `6 → 3`으로 낮췄다.
3. 후속 MVP-3 승인 설계는 오의 비전서를 모든 유파에 유효하게 연결하기 위해 흑영류의 표식 지속시간 채널을 명시했다.
4. MVP-3 구현 계획은 `BASE_MARK_DURATION := 8.0`과 exact-expiry RED/GREEN 테스트를 잠갔다.
5. PR #4가 병합되며 8초 표식, 지속시간 modifier, 만료·재계산 테스트가 main에 통합됐다.
6. 2026-08-20 최신 유파 방향은 흑영류를 `우선 처형`으로 강화했지만 표식 지속시간을 다시 무기한으로 되돌린 결정은 없다.

따라서 과거 MVP-2의 무기한 문구는 **`SUPERSEDED_BY_APPROVED_MVP3_MARK_LIFETIME`**로 분류한다.

## 비교 대안

### A · 무기한 유지

장점:

- 표식 손실 스트레스가 없다.
- 최초 MVP-2 문구와 일치한다.

문제:

- 전장에서 멀어진 적·우선순위가 바뀐 적의 표식이 장시간 남아 오의 준비를 왜곡할 수 있다.
- 표적 집중과 처형 리듬보다 여러 적에게 표식을 흩뿌린 뒤 기다리는 플레이가 유리해질 수 있다.
- 오의 비전서의 흑영류 효과가 사라지거나 다른 신규 전용 효과를 다시 만들어야 한다.
- 후속 승인 설계·병합 runtime·테스트를 되돌리는 변경이 된다.

비채택.

### B · 8초 갱신형, 대상별 일괄 만료 · **현재 정본**

장점:

- 현재 구현·테스트·MVP-3 아이템 연결을 그대로 보호한다.
- 만천화우 기본 주기 `1.10초`에 비해 충분히 긴 유예 시간이어서 정상 집중 공격 중에는 쉽게 끊기지 않는다.
- 대상 전환·거리 이탈·위험 회피에는 실제 비용이 생겨 흑영류의 `우선 표적 선정 → 표식 누적 → 처형` 리듬을 만든다.
- 만료가 오래된 전장 상태와 오의 준비 수치를 자동 정리한다.

채택.

### C · 중첩별 순차 감쇠

예: 일정 시간이 지나면 `MARK 2 → MARK 1 → 0`으로 한 중첩씩 감소.

장점:

- 표식이 한 번에 사라지는 손실감을 줄일 수 있다.

문제:

- 중첩별 타이머 또는 감쇠 상태가 필요해 데이터·UI·테스트가 복잡해진다.
- 플레이어가 만료 시점을 예측하기 어려워진다.
- 현재 구현과 아이템 modifier를 불필요하게 재작성한다.

첫 Vertical Slice에서는 비채택. 8초 일괄 만료가 플레이테스트에서 반복적으로 불공정하다고 확인될 때만 재검토한다.

## 전투 규칙

### 표식 부여와 갱신

- 대상별 가시 표식은 `MARK 1` 또는 `MARK 2`다.
- 정상 타격은 기본 1중첩, 치명타는 기본 2중첩을 부여한다.
- 기존 중첩과 합산해 3 이상이 되면 MARK BURST를 일으키고 해당 대상의 표식을 0으로 초기화한다.
- 합계가 1~2이면 남은 지속시간을 유효 지속시간 전체로 갱신한다.
- 표식 자원 획득 modifier의 소수 누적 credit 규칙은 기존 MVP-3 구현을 유지한다.

### 오의 준비

- 암영처형 준비 기준은 후속 수동 조정대로 **유효한 살아 있는 적 전체의 활성 표식 합계 3 이상**이다.
- 표식 만료·적 사망·Burst·오의 사용으로 활성 합계가 3 미만이 되면 준비 상태도 즉시 해제된다.
- 이미 Burst된 표식은 오의 준비에 남지 않는다.

### 아이템·운명과의 연결

- `오의 비전서`는 흑영류에서 표식 지속시간 `+25%`를 제공한다.
- `봉인의 길`의 오의 준비 보정은 기존 설계대로 표식 지속시간 채널에 더해진다.
- `유파 증표`는 표식 지속시간이 아니라 표식 대상 치명타 확률을 높인다.
- `깨달음`·금기의 길 등 자원 획득 보정은 기존 fractional mark credit 규칙을 사용하며 표식 지속시간을 직접 바꾸지 않는다.
- 백팩 공간·인접·조합이 추가되어도 이 역할 분리를 유지한다.

## 보스·Stage 규칙

- Stage 1~4 난이도 보정은 적 HP·피해·spawn·패턴·유파 기믹 깊이를 조정하지만 플레이어 암영표식의 기본 8초를 숨겨서 단축하지 않는다.
- 일반 적, Elite, 유파 Boss, 난세 재앙핵은 원칙적으로 표식 면역을 갖지 않는다.
- 보스의 정상 이동·돌진·순간 재배치는 표식 시간을 멈추지 않는다.
- 플레이어가 공격하거나 갱신할 수 없는 **시스템 강제 컷신/장시간 무적 전환**이 존재한다면 그 비상호작용 시간에는 표식 타이머를 정지시키는 방향을 보스 구현 계약으로 사용한다.
- 짧고 전투적인 회피 패턴까지 타이머를 정지시키지는 않는다.

## UI / 피드백 계약

현재 `MARK 1 / MARK 2` 배지는 유지한다.

최종 Visual 단계 권장 기본값:

- 남은 시간이 충분하면 일반 표식 배지.
- 마지막 약 `2.0초`에는 색상 변화만이 아니라 **맥동/깜박임 또는 외곽선 수축**을 함께 사용해 만료 임박을 알린다.
- 새 표식을 부여해 시간이 갱신되면 경고 상태가 즉시 해제된다.
- 초 단위 숫자 카운트다운은 첫 Vertical Slice에서 필수로 넣지 않는다.
- 다수 적이 동시에 표식됐을 때 경고 VFX가 전투 telegraph를 덮지 않도록 크기·광량을 제한한다.

이 UI 경고는 제품 runtime에 아직 구현됐다고 주장하지 않는다.

## 적대적 검토

### Loop 1 · 첫 플레이 공정성

위험: 표식이 이유 없이 사라진 것처럼 보일 수 있다.

보호: 8초는 기본 공격 주기 대비 충분히 길게 유지하고, 마지막 2초 비색상 경고를 Visual 계약에 둔다.

### Loop 2 · 무기한 표식의 수동성

위험: 여러 적에게 표식만 남기고 안전하게 도망치며 오의를 보존하는 방식이 우선 처형 정체성을 약화한다.

보호: 갱신형 지속시간으로 현재 우선 표적을 계속 압박해야 한다.

### Loop 3 · Boss 불공정

위험: 긴 강제 연출 중 표식이 사라질 수 있다.

보호: 플레이어가 개입할 수 없는 강제 비상호작용 구간에만 타이머 정지를 허용한다.

### Loop 4 · 아이템 의미 충돌

위험: 무기한으로 되돌리면 오의 비전서의 흑영류 효과가 무효화된다.

보호: 후속 MVP-3의 지속시간 modifier 매핑을 정본으로 유지한다.

### Loop 5 · 과도한 복잡성

위험: 중첩별 개별 타이머·순차 감쇠·별도 표식 관리 UI가 MVP 범위를 늘린다.

보호: 대상별 단일 갱신 타이머와 일괄 만료만 사용한다.

## 검증 계약

### 이미 존재하는 자동 증거

- 기본 표식이 `7.99초`에는 남고 `8.00초`에 제거된다.
- 오의 비전서 25% 적용 시 `10.0초`가 된다.
- 오의 비전서와 봉인의 길 준비 보정 합계 55%에서 `12.4초`가 된다.
- modifier가 기존 표식에 재적용되면 남은 시간 비율을 보존해 재스케일한다.
- 적 삭제·runtime 비활성화 시 표식과 배지가 제거된다.

### 향후 구현/회귀 요구

- 1~2중첩에 새 표식을 부여하면 유효 지속시간 전체로 갱신되는 focused test.
- 만료 직전 경고가 시작되고 갱신 시 해제되는 UI test.
- 만료로 활성 표식 합계가 3 미만이 되면 암영처형 준비 상태가 즉시 해제되는 test.
- 강제 보스 전환 타이머 정지는 실제 해당 패턴이 구현될 때만 test.
- 다른 유파 흔적·백팩 아이템을 획득해도 시작 흑영 runtime의 기본 지속시간 정본이 자동 교체되지 않는 regression.

### Human play 질문

- 표식이 사라진 이유와 만료 임박을 전투 중 읽을 수 있는가.
- 8초가 실수 한 번을 용서하면서도 장기간 방치된 표식을 정리하는가.
- 오의 비전서가 숫자만 늘리는 아이템이 아니라 표적 전환 여유를 체감시켜 주는가.
- Boss 이동 때문에 표식이 반복적으로 억울하게 끊기지 않는가.
- 표식을 여러 적에게 흩뿌리는 방식과 위험 표적을 집중 처형하는 방식 중 후자가 더 기억에 남는가.

## 명시적 보호·제외

- 현재 `scripts/schools/heukyeong_runtime.gd`와 관련 테스트는 이 문서 때문에 수정하지 않는다.

- 흑영류의 별도 수동 표적 클릭 UI는 추가하지 않는다.
