## DEC-2026-08-20-016 · 유파 흔적 = Run 전승 잔향 + 최종 결속

상태: `APPROVED_BY_USER_2026-08-20`

### 핵심 정의

- 각 유파 전장에서 회수하는 `유파 흔적`은 닌자소울과 다른 **Run 전용 진행/빌드 자원**이다.
- 문자 그대로의 죽은 자 영혼이 아니라, 해당 유파가 전장에 남긴 **전승·술식·기량·의지의 잔향**을 회수한 것으로 해석한다.
- 한 Run에서 봉마·천술·귀인·흑영 흔적을 각각 정확히 1개씩 회수한다.
- 흔적은 메타 영구 화폐가 아니며 Run 종료 시 현재 Run 보유 상태는 초기화된다.
- `닌자소울`은 Run 밖 지부 전승 복구, `유파 흔적`은 Run 안 경로/최종전 준비라는 역할을 분리한다.

### 획득/안정화 흐름

```text
유파 전장 진입
→ 해당 유파의 핵심 기믹/적 조합 경험
→ 전장 후반부에 유파 흔적 회수
→ 흔적 회수로 유파 Boss 접근/출현 조건 충족
→ 해당 유파 Boss 격파
→ 지부 귀환 시 흔적 안정화
→ 남은 Run 동안 해당 유파 전승 효과 활성
```

- 흔적 자체를 줍는 순간 Boss를 약화시키는 `정답 키`로 사용하지 않는다.
- Boss를 격파한 뒤 흔적이 안정화되어 이후 스테이지의 빌드 방향에 영향을 주게 한다.
- 먼저 간 유파의 흔적은 더 많은 후속 스테이지에서 사용할 수 있으므로 **자유 경로 선택의 전략적 가치**가 생긴다.
- 다만 첫 번째 흔적만 지나치게 큰 snowball을 만들지 않도록 효과 예산은 제한한다.

### 흔적의 Run 효과 원칙

각 흔적은 `작은 범용 바닥 효과 + 해당 유파 태그/플레이 철학을 강화하는 주 효과` 구조를 우선한다. 정확한 수치는 후속 밸런스 단계의 `RECOMMENDED_DEFAULT`로 둔다.

| 흔적 | 주 강화 방향 | 빌드 의미 |
|---|---|---|
| 봉마 흔적 | 소환·설치·결계·지속효과 | 장기 유지/전장 장악 빌드가 더 안정됨 |
| 천술 흔적 | 상태·원소·반응 | 반응/상태를 이용한 연쇄 빌드가 더 가치 있어짐 |
| 귀인 흔적 | 근접·생존·위험 유지 | 가까이 붙어 싸우는 빌드의 위험/보상 효율 강화 |
| 흑영 흔적 | 원거리·투척·치명·우선처형 | 위험 표적을 빠르게 제거하는 빌드 강화 |

보호 규칙:
- 흔적 하나가 `공격력 +30%`처럼 모든 빌드에 동일한 큰 수직 버프가 되지 않는다.
- 해당 태그가 없는 빌드에서도 완전한 dead reward가 되지 않도록 작은 범용 효용을 가진다.
- 흔적 때문에 특정 자유 경로 순서가 사실상 강제되는 경우 실패로 본다.

### 4흔적 최종 결속

4번째 유파 Boss를 격파하고 공동 지부의 마지막 휴식에 들어가면 4흔적을 **하나의 최종 전승 결속**으로 묶는다.

- 4흔적 보유는 별도 Run 최종 Boss 진입의 서사/시스템 선행 조건이다.
- 단순 문 열쇠로만 끝내지 않고, 마지막 Workbench/Fate에서 **회수한 네 전승 중 하나의 면모를 최종전에서 더 강하게 발현하는 `최종 준비 선택` 1회**를 제공하는 방향을 승인한다.
- 네 흔적은 모두 소비/결속되며, 선택하지 않은 흔적이 사라진 것으로 해석하지 않는다. 네 전승은 모두 결속되고 그중 한 면모를 전투 준비에서 전면화한다.
- 최종 준비 선택은 새 경제나 장기 메뉴가 아니라 기존 마지막 휴식 Flow 안의 짧은 4-card/4-option 선택으로 구현 가능한 범위를 우선한다.
- 정확한 이름, 수치, 최종 Boss와의 상호작용 세부는 후속 최종보스 Decision에서 정한다.

# 봉마류 Encounter Ecosystem

판타지: **소환·봉인·결계가 전장을 점유하고 서로를 강화한다.**

### Core Monster

1. `파지 식신` · Swarm
   - 작은 식신/잔령이 짧게 플레이어를 따라붙고 예고 후 돌진.
   - 단독으로는 단순하지만 여러 마리가 결계 안에서 강화될 수 있다.

2. `봉진술사` · Priority Threat
   - 일정 시간 멈춰 명확한 원형/선형 봉인진을 생성.
   - 봉인진은 짧은 시간 주변 적의 공격 주기/행동을 강화하거나 플레이어 동선을 나눈다.
   - 플레이어의 소환을 삭제하거나 스킬을 봉쇄하지 않는다.

3. `결계귀` · Anchor
   - 느리고 체력이 높은 대형 요괴/잠식체.
   - 주기적으로 짧은 결계 핵을 생성해 공간을 점유.
   - 단순 HP sponge가 아니라 이동 경로를 바꾸는 역할.

### Elite · `파계 감찰관`

- 소수 식신 소환 + 예고된 결계 1~2개를 조합.
- 결계 위치를 옮기며 전선을 재형성하도록 압박.
- 특정 소환/결계 빌드에 대한 면역은 금지.

### Boss · `잠식 봉마 전승자`

- 잠식 식신 1~2체.
- 짧은 봉인진/결계 연결.
- HP 임계에서 식신/결계 배치 cadence가 증가.
- 핵심 시험은 `지속 장악을 누가 더 잘 유지하는가`가 아니라 **적이 만든 공간 장악을 읽고 이동하며 내 빌드의 장악을 유지하는가**다.

### Stage 기믹 확장

- Stage 1: 식신 + 단일 짧은 봉인진.
- Stage 2: `결계 공명` 추가. 결계 안의 식신/적이 짧게 강화되므로 위치를 바꾸거나 결계 생성자를 우선 처리.
- Stage 3: `연결 봉인` 추가. 두 봉인점 사이 선형 예고가 생기고 잠시 위험선 형성.
- Stage 4: `이동 봉진` 추가. Boss/Elite가 기존 봉인점을 재배치하며 식신과 연계. 화면 동시 고급 결계는 2개 수준으로 제한.

# 천술류 Encounter Ecosystem

판타지: **원소 상태 자체보다 서로 다른 상태가 만날 때 전장이 바뀐다.**

### Core Monster

1. `화령` · Swarm
   - 짧은 예고 후 화염 공격/작은 화염 흔적을 남김.
   - 죽음 폭발은 즉발이 아니라 명확한 예고를 사용.

2. `수뢰술사` · Priority Threat
   - 물/번개 계열 원거리 영역을 교대로 배치.
   - 단독 피해보다 다른 원소 영역과 만날 때의 반응 위협이 핵심.

3. `토갑귀` · Anchor
   - 느린 대형 원소 요괴.
   - 짧은 시간 원소 반응의 중심점/전장 Anchor 역할을 하며 동선을 제한.

### Elite · `오행 집행관`

- 두 원소 패턴을 순서대로 사용.
- 겹치는 영역이 명확한 지연 후 반응해, 플레이어가 위치를 읽고 반응 지점을 피하거나 유도할 수 있게 함.

### Boss · `잠식 천술 전승자`

- 불/물/번개 계열의 명확한 영역 패턴.
- 두 상태가 만날 때 강화 반응.
- MVP-2의 `화둔 하나가 WET/SHOCK을 번갈아 부여`하는 테스트 장치를 세계관 규칙으로 복사하지 않는다.

### Stage 기믹 확장

- Stage 1: 단일 원소 영역을 순차적으로 읽는 단계.
- Stage 2: `2원소 반응` 추가. 두 영역 겹침이 첫 조합 기믹.
- Stage 3: `반응 연쇄` 추가. 한 반응이 가까운 두 번째 영역을 지연 활성화할 수 있음.
- Stage 4: `오행 순환` 고급 패턴. Boss/Elite가 3종 원소 순서를 사용하지만 한 번에 읽어야 하는 핵심 반응은 1~2개로 제한.

# 귀인류 Encounter Ecosystem

판타지: **가까이 붙어 압박을 오래 유지할수록 적도 강해지며, 이탈 타이밍이 중요하다.**

### Core Monster

1. `혈귀 잔병` · Swarm
   - 짧은 근접 돌진/연속 베기.
   - 오래 근접할수록 공격 템포가 조금 상승하되 가시적 분노 표시 사용.

2. `귀혈 투사` · Priority Threat
   - 예고된 장거리 돌입 후 짧은 연타.
   - 적중에 성공하면 자신의 귀혈/분노가 상승하지만 빗나가면 긴 회복 창 제공.

3. `귀갑 중장` · Anchor
   - 느린 대형 근접 압박체.
   - 플레이어 근처에 오래 머물수록 가시적인 귀혈 Aura가 상승하며 큰 공격을 준비.

### Elite · `혈전장`

- 근접 압박을 연속 유지하면 귀혈이 상승.
- 큰 공격은 충분히 예고되고, 플레이어가 이탈하면 상승세를 끊을 수 있음.

### Boss · `잠식 귀인 전승자`

- 접근 → 연속 압박 → 귀혈 상승 → 큰 마무리 공격의 명확한 주기.
- HP가 낮다는 이유 하나로 자동 폭증하는 보스가 아니라 `근접 지속 성공`이 강화 조건.

### Stage 기믹 확장

- Stage 1: 개별 적의 근접/귀혈 상승만 학습.
- Stage 2: `귀혈 임계` 추가. 일정 귀혈 이상 적이 강화 공격을 준비하며 명확한 표시 제공.
- Stage 3: `혈기 공명` 추가. 가까운 귀인 적 2체 이상이 서로의 귀혈 상승을 보조하므로 흩뜨리기/우선 처리가 의미 있음.
- Stage 4: `광전 연계` 추가. Elite/Boss가 한 번의 명확한 Frenzy window를 열어 주변 근접 적이 동시 압박하되, 회피/이탈 가능한 안전 창을 반드시 남김.

# 흑영류 Encounter Ecosystem

판타지: **많이 맞는 것이 아니라 표식이 쌓인 뒤 오는 결정적인 처형이 위험하다.**

### Core Monster

1. `그림자 잔영` · Swarm
   - 짧은 방향 예고 후 순간 이동에 가까운 dash.
   - 사라지는 동안 무적이 아니라 위치 이동 연출로만 사용.

2. `암영 투척수` · Priority Threat
   - 피할 수 있는 투척 공격.
   - 적중 시 플레이어에게 가시적 표식 1단계.
   - 표식 누적은 별도 복잡한 디버프 UI가 아니라 HUD/캐릭터 주변 간단 표시로 읽게 함.

3. `독무 감시자` · Anchor
   - 느린 적으로 짧은 연막/독무 영역을 배치해 동선을 제한.
   - 연막은 telegraph를 가리지 않으며 시각적 은폐보다 **게임플레이 zone**으로 사용.

### Elite · `척살대장`

- 표식 부여 투척 + 짧은 재배치/dash.
- 일정 표식에서 예고된 처형 공격을 시도하며 회피하면 표식 일부/전부를 소모하는 구조를 우선.

### Boss · `잠식 흑영 전승자`

- 표식 축적 → 이동/재배치 → 명확한 처형 창.
- `처형 = 자동 명중`이 아니라 플레이어가 위험을 예측하고 피하는 기술 시험.

### Stage 기믹 확장

- Stage 1: 단일 표식/투척 읽기.
- Stage 2: `연막 재배치` 추가. 연막 안 적이 짧게 위치 변경 기회를 얻지만 공격 예고는 계속 표시.
- Stage 3: `표식 연계` 추가. 여러 적이 같은 표식 임계에 기여할 수 있으나 동시에 처형 공격은 하나만 활성.
- Stage 4: `암영 척살 연계` 추가. 연막 + 표식 + 재배치를 한 사이클로 묶되 처형 예고와 안전 이동 경로를 명확히 유지.

## StageGimmickProfile · 공통 구조

DEC-015의 수치 보정에 **기믹 단계**를 추가한다.

| stage | scalar pressure | school gimmick layer |
|---:|---|---|
| 1 | baseline | Base signature만 |
| 2 | HP/피해/spawn 소폭 상승 | 유파 `Interaction Gimmick` 1개 추가 |
| 3 | 중간 상승 | `Synergy/Field Gimmick` 추가 |
| 4 | 가장 높은 공통 보정 | `Mastery Gimmick` + Boss 고급 패턴 1개 |

중요:
- Stage 4는 Stage 1~3의 모든 위험을 항상 동시에 쌓는 방식이 아니다.
- Encounter Director는 고급 기믹 라이브러리 중 **동시 활성 핵심 기믹 최대 2개**를 기본 상한으로 한다.
- 새 기믹은 기존 telegraph/행동을 조합해 난이도를 올리고, 화면을 읽을 수 없게 만드는 수량 폭증을 피한다.
- Stage가 올라갈수록 `새 규칙을 암기`하는 것보다 `이미 배운 유파 규칙이 서로 연계`되는 느낌을 우선한다.
- 유파에 따라 Stage 4에서 새 입력/새 UI/새 별도 자원을 요구하지 않는다.

```text
SchoolEncounterDefinition
  ├─ SchoolMonsterRoster
  ├─ SchoolEliteDefinition
  ├─ SchoolBossDefinition
  └─ SchoolGimmickLibrary

StageDifficultyProfile(stage_index)
  ├─ hp/damage/spawn/cadence scalar
  └─ unlocked_gimmick_tier

SchoolTraceDefinition
  ├─ run modifier identity
  └─ final manifestation identity

SchoolEncounterDefinition
+ StageDifficultyProfile
+ current SchoolTraceState
+ RunBuildState
→ EncounterSnapshot
```

- `school_id × stage_index` 16개 조합을 각각 독립 하드코딩하지 않는다.
- 몬스터 locomotion, telegraph, projectile, summon, zone, mark, rage 같은 컴포넌트는 재사용한다.
- 유파 정체성은 **컴포넌트 조합/파라미터/아트/VFX/패턴 문법**으로 만든다.

## 5회 전체 적대적 검토

### Full Loop 1

전체 구조를 `정체성 / 경로 전략 / 가독성 / 제작비 / 장기 확장` 관점으로 다시 공격했다.

발견:
- 유파마다 완전 신규 AI를 만들면 12+4+4 콘텐츠가 solo scope를 초과할 수 있음.
- 흔적이 단순 수치 버프면 자유 경로가 `가장 강한 버프 먼저` 하나로 수렴할 수 있음.

수정:
- 공통 role/behavior component chassis를 재사용하고 school kit 조합으로 차별화.
- 흔적은 큰 범용 수직 스탯이 아니라 `작은 범용 floor + school-tag synergy` 구조.

### Full Loop 2

동일 구조를 다시 `공정성 / 자동전투 / 근접·원거리 균형 / route order / boss 학습` 전체 관점으로 검토했다.

발견:
- 후반 Stage 기믹이 특정 유파를 직접 봉쇄하면 자유 선택이 사실상 함정 선택이 됨.
- 흑영 연막이 telegraph를 가리거나 귀인 근접 압박이 이탈 불가능하면 불공정.

수정:
- 유파 하드카운터/면역 금지.
- 연막은 시각 가림 대신 zone으로 사용.
- 귀인 강화에는 명확한 이탈/리셋 창 보장.

### Full Loop 3

전체를 다시 `온보딩 / Stage 1→4 학습 곡선 / 화면 정보량 / 5분 cadence / overtime` 관점으로 검토했다.

발견:
- Stage 4에 1~3 모든 기믹을 상시 중첩하면 읽을 수 없음.
- 3분 Elite 이후 새 규칙을 또 가르치면 Boss 직전 과부하.

수정:
- Stage 4에서도 핵심 고급 기믹 동시 활성 기본 상한 2개.
- Stage 상승은 새 규칙 수보다 기존 규칙의 `연계`를 강화.
- Elite는 Boss 기믹을 일부 예고하되 새 시스템 전체를 한꺼번에 도입하지 않음.

### Full Loop 4

전체를 다시 `빌드 다양성 / 보상 / 흔적 snowball / 자유 경로 의미 / 재플레이` 관점으로 검토했다.

발견:
- 첫 흔적이 너무 강하면 가장 강한 학교를 먼저 도는 고정 루트가 생김.
- 반대로 흔적이 너무 약하면 자유 경로 선택의 보상 의미가 사라짐.

수정:
- 흔적은 뒤 스테이지 빌드 방향에 체감 가능한 영향은 주되 direct universal DPS budget을 제한.
- route UI는 `위험 / Boss 철학 / 흔적 성격 / Stage 위험도`를 같이 보여 전략적 선택으로 만듦.
- 정확한 흔적 수치는 플레이테스트에서 route pick-rate 편향을 기준으로 튜닝.

### Full Loop 5

전체를 다시 `세계관 / 유파 악역화 / 최종보스 연결 / 메타 중복 / 구현 현실성` 관점으로 검토했다.

발견:
- 유파별 몬스터/보스가 전부 악한 유파 구성원처럼 보일 수 있음.
- 유파 흔적과 닌자소울이 모두 `영적 자원`처럼 읽히면 용도가 겹침.

수정:
- 적 roster는 `잠식된 닌자 / 왜곡된 식신 / 유파가 다루던 요괴·전승의 잔재`를 혼합하고 유파 조직 전체를 악역화하지 않음.
- 닌자소울 = Run 밖 전승 복구, 유파 흔적 = Run 안 전장 회수/경로/최종전 준비로 분리.

## 장기 재검토 조건

- 유파별 3몬스터만으로 전장 반복성이 빠르게 드러나면 `4번째 rare specialist`를 우선 추가한다. 처음부터 일반 몬스터 수를 과도하게 늘리지 않는다.
- Stage 4가 수치 스펀지로 느껴지면 HP 배율을 더 올리지 말고 existing gimmick synergy/cadence를 먼저 조정한다.
- Stage 3~4 기믹이 화면 판독을 방해하면 기믹 종류를 삭제/교체하고, 단순히 VFX를 줄이는 것으로 문제를 숨기지 않는다.
- 특정 유파가 Stage 4에서 지속적으로 선택 기피되면 해당 유파 base threat budget 또는 Stage gimmick interaction을 조정한다. 자유 선택 자체를 제거하지 않는다.

## 최종 한 줄

**`각 유파는 전용 몬스터 3종·Elite 1종·Boss 1종·기믹 라이브러리를 가지며, 자유 선택된 유파 정체성 위에 Stage 1→4 진행도에 따라 공통 수치 보정과 추가 유파 기믹 레이어가 적용된다. 유파 흔적은 Boss 이전에 회수되고 Boss 격파 후 안정화되어 Run 빌드에 작은 유파 전승 효과를 주며, 네 흔적은 마지막 휴식에서 최종 전승 결속으로 합쳐져 별도 최종보스 준비에 사용된다.`**
