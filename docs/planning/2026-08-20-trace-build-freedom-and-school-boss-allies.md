## DEC-2026-08-20-019 · 유파 흔적은 자동 강화가 아니라 전승 접근권

상태: `APPROVED_BY_USER_2026-08-20`

### 보정 핵심

이 결정은 DEC-016의 `유파 흔적 자체가 해당 유파 태그/플레이 철학을 자동 강화한다` 해석을 보정한다.

**닌자 서바이벌의 Run 파워는 백팩에서 결정한다.**

- 유파 흔적 자체는 공격력/체력/유파 태그를 자동으로 올리는 전투 버프가 아니다.
- 유파 Boss를 격파하고 흔적을 안정화하면 해당 유파의 인법·장비·조합 재료가 **현재 Run의 후속 보상/상점 후보 풀에 개방**된다.
- 플레이어는 그 유파를 섞을 의무가 없다.
- 시작 유파/현재 빌드를 더 강화해도 되고, 방금 해방한 유파를 백팩에 섞어도 되고, 여러 유파를 조합해도 된다.
- 실제 전투력은 `어떤 아이템/인법을 획득했는가 → 백팩에 무엇을 배치했는가 → 어떤 인접/조합을 만들었는가`가 결정한다.

### Boss 격파 후 기존 보상 구조 활용

새로운 별도 성장판을 만들지 않는다. 기존 `Boss reward 3 options → choose 1`과 Workbench/Shop을 사용한다.

Boss 격파 직후 초기 authoring 원칙:

1. **현재 빌드 강화 후보**
   - 시작 유파 또는 현재 백팩의 주요 태그/조합 방향을 더 밀 수 있는 후보.
2. **해방 유파 전승 후보**
   - 방금 격파한 유파의 인법/장비/조합 재료 후보.
3. **가교 후보**
   - 현재 빌드와 해방 유파 사이를 잇는 중립/혼합 태그, 조합 재료, 배치 시너지 후보.

정확히 매번 이 세 범주가 1:1:1로 강제될 필요는 없지만, 첫 Vertical Slice의 설명성과 선택 자유 검증에는 이 구성을 기본값으로 둔다.

### 후속 획득 풀

흔적 안정화 이후:

- Boss reward, Shop, Chest 등 기존 획득 경로에서 해방 유파 후보가 등장할 수 있다.
- 획득 경로를 새로 추가하지 않는다.
- `흔적 보유 = 해당 유파 기술 자동 장착`이 아니다.
- `흔적 보유 = 해당 유파 후보가 Run에서 합법적으로 열림`이다.
- 플레이어가 실제로 그 유파 인법/장비를 백팩에 넣지 않으면 그 유파 전투 효과도 발생하지 않는다.

### 시작 유파의 의미 보호

- 시작 유파는 Run 시작 시 기본 전투 인법/고유 앵커/오의와 첫 플레이 판타지를 결정한다.
- 다른 유파 흔적을 회수했다고 시작 유파가 교체되지는 않는다.
- 다만 Run이 진행되면서 백팩을 통해 다른 유파 인법과 장비를 섞을 수 있다.
- 최종 빌드는 `단일 유파 심화`, `2유파 혼합`, `다유파 조합` 모두 가능해야 한다.
- 특정 혼합이 항상 단일 유파보다 우월하거나, 반대로 시작 유파 순혈만 정답이 되면 실패다.

### 흔적과 최종 결속

- 흔적은 여전히 4유파 평정 진행도와 최종재앙 진입의 서사/시스템 증거다.
- 4흔적을 마지막 휴식에서 결속하지만, `네 흔적 중 하나를 골라 그 유파를 자동 대폭 강화`하는 과거 해석은 재검토한다.
- 최종 휴식의 선택도 백팩을 우회하는 새 성장축이 아니라 **현재 완성된 백팩 빌드의 방향을 읽고 보조하는 짧은 최종 준비**여야 한다.
- 정확한 최종 준비 효과는 후속 밸런스/최종전 설계에서 잠근다.

## DEC-2026-08-20-020 · 해방된 4유파 Boss는 최종전에서 각 1회 지원

상태: `APPROVED_BY_USER_2026-08-20`

### 서사 핵심

각 유파 Boss는 단순히 처치해서 사라지는 적이 아니다.

- Boss의 정체는 전란·금기·요기·잠식에 휘말려 자기 유파의 전승을 왜곡해서 사용하던 인물/수호자/전승자 계열을 우선한다.
- 플레이어가 Boss를 격파하고 유파 흔적을 안정화하는 과정은 **죽여 없애는 것**보다 `잠식과 내분에서 해방/제압/정화`하는 의미를 우선한다.
- 해방된 각 유파 Boss/대표자는 공동 지부의 마지막 결속에 응하고, 난세 재앙핵과의 최종전에서 **각자 한 번씩 지원**한다.
- 이것이 `4유파의 내분 → 재결속` 서사의 전투적 결산이다.

### 빌드와 동맹의 분리

- 플레이어가 해당 유파 아이템을 백팩에 사용했는지와 Boss 지원 여부는 무관하다.
- 예: 천술 흔적을 회수했지만 천술 아이템을 하나도 채용하지 않아도, 천술 Boss/대표는 최종전에 지원한다.
- 이유: `전승 사용 여부`는 빌드 선택이고, `유파를 해방했는가`는 세계/서사 진행이기 때문이다.

### 지원 조작 원칙

권장: **자동/상황 트리거 1회성 개입**.

- 별도 소환 버튼 4개, 쿨다운 UI, 동료 관리창을 만들지 않는다.
- 각 동맹은 최종 Boss의 정해진 전투 이벤트/HP 구간/위험 고조 시 한 번 등장한다.
- 지원은 필수 파훼를 대신하는 `정답 버튼`이 아니다.
- 지원 없이 피할 수 없는 공격을 만들어서는 안 된다.
- 지원의 목적은 `위험 완화 + 짧은 공격 창 + 서사 콜백`이다.

### 자유 경로 기억

**지원 순서는 플레이어가 4유파를 평정한 순서를 기본으로 반영**한다.

예:

```text
Run route: 흑영 → 봉마 → 귀인 → 천술
Final ally callbacks: 흑영 → 봉마 → 귀인 → 천술
```

- 자유 경로 선택이 최종전 연출에도 남는다.
- 지원 효과의 총 예산은 순서에 따라 유불리가 과도하게 생기지 않게 정규화한다.
- 특정 유파를 4번째로 두면 최종전에서 무조건 유리해지는 고정 메타가 생기면 실패다.

### 유파별 1회 지원 working design

최종 이름/애니메이션/정확 수치는 Visual/Balance 단계에서 확정한다.

#### 봉마 지원 · `결계 재건`
- 잠식 결계/요기 영역 일부를 짧게 안정화한다.
- 식신/봉인으로 잡몹 또는 공간 압박을 정리하고 짧은 안전/공격 창을 만든다.
- 플레이어 소환 빌드 여부와 무관하게 유효하되, 큰 직접 DPS보다 `전장 안정`이 정체성이다.

#### 천술 지원 · `오행 정류`
- 현재 활성화된 위험 영역/요기 흐름 일부를 원소 반응으로 정리한다.
- Boss에 짧은 stagger/취약 창 또는 위험장 정리를 제공하는 방향을 우선한다.
- 화면 전체 즉사급 폭발이 아니라 `혼란을 질서 있는 반응으로 되돌림`이 감정 목표다.

#### 귀인 지원 · `혈전 돌파`
- Boss의 강한 압박 순간에 정면으로 돌입해 큰 공격을 끊거나 Boss를 잠깐 붙잡아 공격 창을 만든다.
- 플레이어 대신 피해를 무한히 받아주는 탱커가 아니다.
- `가장 위험한 순간에 몸으로 전선을 연다`가 정체성이다.

#### 흑영 지원 · `암영 척살`
- 재앙핵의 순간적 약점/핵을 표식하고 빠르게 일격을 가해 짧은 취약 구간을 연다.
- Boss 체력을 비율로 삭제하는 처형이 아니라 `핵심 위험을 드러내고 우선 제거한다`는 철학을 표현한다.

### 최종전 감정선

```text
4유파가 서로 싸움
→ 요기와 금기가 폭주
→ 각 유파가 잠식/왜곡됨
→ 플레이어가 네 전장을 하나씩 평정
→ 흔적/전승을 다시 연결
→ 최종재앙 앞에서 네 유파가 다시 한 편에 섬
→ 플레이어 + 4유파의 결속이 난세 재앙핵을 평정
```

플레이어는 네 Boss의 도움을 받아도 주인공 자리를 빼앗기지 않는다.

- 동맹은 각자 1회만 전장을 열어 준다.
- 실제 Boss HP를 깎고 빌드를 완성해 승리하는 주체는 플레이어다.
- 마지막 결정타/결산은 플레이어의 백팩 빌드와 전투가 담당한다.

## 적대적 검토

### 1. 흔적이 새 특성 트리로 변질될 위험
대응: 흔적은 자동 스탯 버프가 아니라 **획득 풀 개방 + 세계 진행 증거**. 전투력은 백팩으로 만든다.

### 2. 타 유파 개방이 시작 유파 의미를 지울 위험
대응: 시작 유파의 기본 runtime/앵커/오의는 유지. 타 유파는 획득·배치해야 실제 사용 가능하다.

### 3. 혼합 빌드가 무조건 정답이 될 위험
대응: 단일 유파 심화와 혼합의 효과 예산을 동일 원칙으로 관리하고, `유파 수가 많을수록 자동 보너스` 같은 단순 다색 보상을 금지한다.

### 4. 동맹 지원이 scripted win이 될 위험
대응: 지원은 한 번의 위험 완화/공격 창일 뿐. 필수 파훼와 최종 결정타는 플레이어가 담당한다.

### 5. 자유 경로가 최종 지원 순서 메타로 굳을 위험
대응: 네 지원의 기대 전투가치 예산을 맞추고, 순서는 연출/전투 리듬 차이로 남기되 명백한 최적 순서가 생기면 트리거 타이밍을 조정한다.

## 벤치마크에서 가져오는 원리

- Hades의 Companion 계열처럼 **관계를 통해 확보한 동료가 전투에 짧게 개입하는 구조**는 `1회성 지원이 주인공의 직접 전투를 대체하지 않는다`는 원리 참고에 적합하다.
- OCTOPATH TRAVELER 계열의 `각기 다른 기술/정체성을 가진 동료를 어떤 식으로 조합할지 플레이어가 결정`하는 원리는 `유파 개방 ≠ 강제 사용` 설계와 맞는다.
- 외부 작품의 캐릭터/기술/연출을 복제하지 않고 구조 원리만 참고한다.

## 최신 한 줄

**`유파 흔적은 해당 유파를 자동 강화하지 않고 그 전승을 Run의 획득 풀에 개방한다. 플레이어는 시작 유파 심화·타 유파 채용·혼합 조합 중 자유롭게 백팩을 구성한다. 해방된 4유파 Boss/대표는 최종전에서 평정 순서대로 각 한 번씩 개입해 난세 재앙핵의 위험을 낮추고 공격 창을 열며, 실제 승리는 플레이어의 백팩 빌드가 완성한다.`**
