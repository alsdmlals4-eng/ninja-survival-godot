## DEC-2026-08-20-003 · 난세를 평정하는 「닌자의 신」 전설

상태: `APPROVED_BY_USER_2026-08-20`

### 승인된 핵심

- 옛 전설에는 **천하가 난세에 빠질 때 「닌자의 신」이 나타나 혼란을 평정한다**는 이야기가 전해진다.
- 「닌자의 신」은 처음부터 플레이어에게 주어진 공식 직위나 예정된 혈통이 아니다.
- 플레이어는 네 유파 중 하나의 평범하거나 아직 미완성인 닌자로 현재의 난세를 살아간다.
- 전투·인법·도구·백팩 배치·조합·운명 선택을 통해 자기만의 닌자 방식을 완성하고, 실제 업적이 쌓인 끝에 **후대가 전설의 재림 또는 새로운 「닌자의 신」이라 부를 만한 존재**가 되어 간다.
- 핵심 감정은 `선택받았다 → 증명한다`가 아니라 **`살아남는다 → 강해진다 → 자기 방식을 만든다 → 난세를 평정한다 → 전설이 된다`**다.

### 기존 승인 요소와의 연결

- 4유파: 닌자의 신이 되는 하나의 정답이 아니라 서로 다른 닌자 철학/전투 방식.
- 백팩·조합: 플레이어가 자기 방식의 인법과 도구 체계를 실제로 구성하는 핵심 선택면.
- 운명: 난세에서 어떤 대가와 길을 받아들였는지 누적되는 Run 규칙/서사 선택.
- 닌자소울: 장기 진행과 전설 축적을 연결할 후보이며 정확한 서사적 의미는 후속 Decision에서 확정.
- 최종 결과: 이번 Run에서 어떤 닌자가 되었는지와 전설에 얼마나 가까워졌는지를 기억시키는 결과면.

### 보호 대상

- 기존 MVP-0~3 integrated runtime은 이 결정으로 변경하지 않는다.
- 승인된 MVP-4 `6x6 / 4x3`, Persistent Workbench, 공간 인접·회전·조합 결정은 유지한다.
- 네 유파의 기존 전투 감정과 대표 메커니즘을 삭제하거나 하나의 정답 유파로 수렴시키지 않는다.

### 명시적 비채택

- 태어날 때부터 선택된 구원자/예언된 혈통을 기본 코어로 두지 않는다.
- 네 유파가 단순히 공식 신좌 경쟁 시험을 개최한다는 구조를 기본 코어로 두지 않는다.
- 「닌자의 신」을 처음부터 고정된 최종 악역 한 명의 이름으로 한정하지 않는다.

### 벤치마크 원리 수준 참고

- `SHINOBI: Art of Vengeance`: 닌자 판타지의 행동 동기와 현재 위협을 빠르게 이해시키는 명료성은 참고하되 복수 서사를 복사하지 않는다.
- `Hades`: 반복 성공/실패를 세계와 이야기의 진행으로 연결하는 원리는 참고하되 그리스 신화·가족 서사를 복사하지 않는다.
- 닌자 서바이벌의 변형점은 **플레이 결과가 후대의 전설을 만든다**는 구조다.

## DEC-2026-08-20-004 · 인간의 전란이 요괴의 난을 불러온 복합 난세

상태: `APPROVED_BY_USER_2026-08-20`

### 승인된 핵심

- 과거 「닌자의 신」이 난세를 평정한 뒤 오랫동안 인간 세계와 요괴/이계의 경계는 안정되어 있었다.
- 시간이 흐르며 군벌·닌자 세력·권력자들이 다시 천하의 주도권을 놓고 전쟁하기 시작했다.
- 전쟁이 길어지자 일부 세력은 승리를 위해 **금지된 인법·주술·봉인된 힘**까지 사용했다.
- 반복된 전쟁·죽음·금기의 남용으로 봉인과 영적 경계가 약해지고, 요괴·원혼·잠식이 인간 세계로 퍼졌다.
- 현재의 난세는 인간 전쟁과 초자연 재앙이 서로를 키우는 악순환이다.

```text
인간의 전란
→ 금기의 힘 남용
→ 봉인·영적 경계 붕괴
→ 요괴·원혼·잠식 확산
→ 인간 세력의 추가 무장·금기 사용
→ 더 큰 전란
```

### 플레이/콘텐츠 연결

- 인간계 적: 적대 닌자, 군벌 병사, 용병, 금지 인법 사용자, 잠식된 닌자.
- 초자연 적: 요괴, 원혼, 이계 존재, 난세에서 증폭된 재앙성 존재.
- 복합 보스: 금지 인법과 요괴 힘을 결합한 인간, 인간의 전쟁 때문에 태어나거나 강화된 대요괴 등.
- 지역별로 `누가 무엇을 위해 금기를 썼는가 → 어떤 봉인/경계가 무너졌는가 → 어떤 재앙이 나타났는가`를 변주해 콘텐츠를 확장할 수 있다.

### 장기 방향

- 모든 문제를 한 명의 흑막 탓으로 축소하지 않는다. 개인 악역은 존재할 수 있지만 **난세 자체는 인간의 욕망·전쟁과 초자연 재앙이 연결된 구조적 문제**다.
- 따라서 플레이어의 최종 성장은 단순 최종보스 처치만이 아니라, 악순환을 끊고 천하를 다시 안정시키는 방향과 연결한다.
- 네 유파는 이 재앙에 대응하는 서로 다른 닌자 철학/기술 전통으로 유지한다.

### 보호/비채택

- 기존 적 설정의 `잠식 닌자 + 요괴`를 자연스럽게 보존한다.
- 요괴가 이유 없이 갑자기 나타난 단순 봉인 붕괴만을 코어 원인으로 두지 않는다.
- 네 유파 전체를 난세의 직접 원흉으로 만들지 않는다.
- 특정 유파 하나를 기본 악역 유파로 고정하지 않는다.

### 벤치마크 원리 수준 참고

- `Nioh 2` 등 전란과 초자연 위협이 공존하는 작품에서 **인간 갈등과 요괴 위협을 같은 세계의 문제로 읽히게 만드는 원리**만 참고한다.
- 역사 인물·실제 사건·요괴 설정·서사 구조는 복제하지 않는다.
- 닌자의 신의 차별점은 **금기의 힘이 전쟁을 이기기 위한 도구로 쓰일수록 난세 자체가 더 강해지는 악순환**이다.

## DEC-2026-08-20-005 · 20분 / 4구간 Run 골격

상태: `APPROVED_BY_USER_2026-08-20 / AMENDED_BY_DEC-2026-08-20-006`

### 유지되는 승인 핵심

- 한 Run의 대표 길이는 약 20분이다.
- `약 3분 엘리트 → 약 5분 세그먼트 보스 → RESULT → 보상/Workbench/Fate`의 5분 단위 리듬을 네 번 연결한다.
- MVP/Vertical Slice 단계에서는 4개 고정 구간으로 제작량과 검증 변수를 통제한다.
- 랜덤 월드맵, 다중 분기 노드, 세력 판도 시뮬레이션은 초기 코어에 추가하지 않는다.

### DEC-006에 의해 수정된 부분

- 과거 DEC-005의 **4개 서로 다른 난세 권역을 순례하는 선형 평정 원정** 해석은 최신 사용자 컨셉에 의해 폐기한다.
- 4개 구간은 이제 **무너진 닌자 지부와 그 주변 전선을 중심으로 이어지는 4단계 공세/생존/반격 구간**으로 재해석한다.
- 장기적으로 다른 권역을 방문하는 확장은 가능하지만, 현재 코어의 첫 장소와 감정 중심은 무너진 닌자 지부다.

## DEC-2026-08-20-006 · 무너진 닌자 지부에서 시작하는 생존 전설

상태: `APPROVED_BY_USER_2026-08-20`

### 승인된 핵심 컨셉

- 게임 시작 시점의 중심 장소는 **이미 크게 무너지고 고립된 닌자 지부**다.
- 플레이어는 그 지부에 남아 적들의 연속 공세에서 살아남으려는 아직 미완성인 닌자다.
- 첫 목표는 천하를 구하거나 신이 되는 것이 아니라 **이번 공세에서 살아남고 지부의 마지막 거점을 버티는 것**이다.
- 절망적인 상황 속에서 플레이어는 옛 전설, **“천하가 난세에 빠질 때 「닌자의 신」이 나타나 혼란을 평정한다”**는 이야기를 떠올린다.
- 이 전설은 플레이어를 선택받은 자라고 선언하는 예언이 아니다. 살아남기 위해 싸우는 플레이어가 스스로 붙잡는 희망·기준·상징이다.
- 반복되는 전투와 선택 끝에 플레이어의 실제 행동이 전설과 닮아가며, 최종적으로 후대가 그를 새로운 「닌자의 신」이라 부를 수 있게 된다.

### 첫 세션 감정선

```text
무너진 지부
→ 적의 공세
→ 살아남아야 한다
→ 전설을 떠올린다
→ 첫 전투에서 자기 유파의 힘을 사용한다
→ 전리품/인법/도구를 모은다
→ 지부의 Workbench에서 다음 공세를 준비한다
→ 더 강한 공세를 버틴다
→ 단순 생존에서 주변 전선 안정화와 반격으로 목표가 커진다
→ 난세를 평정할 힘과 방식이 만들어진다
→ 전설이 된다
```

### 기존 시스템과의 직접 연결

- **4유파 선택:** 지부에 남은 닌자가 어떤 전통과 전투 철학으로 생존하는지 결정한다.
- **전투 DDD:** 공세를 버티며 처치 콤보·스타일 점수·보상 흡수로 즉시 생존 쾌감을 만든다.
- **Persistent Workbench:** 전투 사이 지부의 남은 장비/인법을 정비하고 다음 공세를 설계하는 diegetic 거점으로 연결하는 것을 우선 후보로 둔다. 정확한 시각 공간은 후속 UX/Visual 결정에서 확정한다.
- **백팩·조합:** 폐허에서 얻은 도구와 인법을 자기 방식으로 다시 엮어 약한 닌자가 강해지는 핵심 성장 표현이다.
- **Fate:** 살아남기 위해 어떤 대가·위험·방식을 받아들일지 정하는 Run의 가치 선택으로 연결한다.
- **보스:** 각 공세를 지휘하거나 증폭시키는 인간/요괴/복합 위협으로 사용한다.

### 20분 / 4구간 재해석

```text
유파 선택 / 무너진 지부
→ 제1 공세 0~5분 · 즉각 생존
   → 약 3분 엘리트 → 약 5분 공세 보스
→ RESULT → 보상 → 지부 Workbench → Fate
→ 제2 공세 5~10분 · 지부 주변 전선 유지
→ RESULT → Workbench → Fate
→ 제3 공세 10~15분 · 반격/공세 근원 접근
→ RESULT → Workbench → Fate
→ 제4 공세 15~20분 · 최종 돌파/지부를 무너뜨리려는 핵심 위협
→ 최종 보스
→ 지부 생존/전선 안정 → 최종 결과 → 전설/닌자소울
```

- 구간마다 완전히 새로운 원거리 지역으로 이동할 필요는 없다.
- 지부 내부, 무너진 성벽/마을, 주변 숲·관문, 공세의 전진기지 등 **같은 거점권을 다른 전투 공간과 위협 단계로 변주**하는 방향을 우선한다.
- 이는 아트·레벨 제작량을 줄이면서도 지켜야 할 장소에 대한 기억과 반복 공세의 긴장감을 강화한다.

### 벤치마크 원리 수준 참고

- `SHINOBI: Art of Vengeance`의 오보로 마을 습격처럼 **익숙하거나 의미 있는 닌자 거점이 공격받는 사건을 첫 행동 동기와 기본 플레이 학습에 결합하는 원리**를 참고하되, 복수극·캐릭터·마을 설정은 복제하지 않는다.
- `The Last Spell`의 **무너진 거점을 지키고 전투 사이 다시 준비하는 구조**에서 장소에 대한 방어 목적과 전투 사이 성장의 결속 원리만 참고한다. 닌자 서바이벌은 타워디펜스/도시건설 게임으로 바꾸지 않는다.
- `20 Minutes Till Dawn`처럼 **제한된 시간 동안 계속되는 공세를 버티면서 빌드를 완성하는 즉시 목표**는 서바이버 장르의 명료성 근거로 참고한다. 조준/총기/밤 설정은 복제하지 않는다.

### 보호/비채택

- 플레이어를 처음부터 예언된 구원자나 「닌자의 신」 후보로 공식 지명하지 않는다.
- 지부 방어 때문에 자동전투 서바이버를 타워디펜스·기지건설 장르로 바꾸지 않는다.
- 벽 HP 관리, 건물 건설, 복잡한 기지 자원 경제를 MVP 코어에 추가하지 않는다.
- 기존 MVP-0~3 전투 기반과 MVP-4 Workbench/백팩 결정을 폐기하지 않고 세계관과 결속한다.

### 장기 적합성 / 재검토 조건

- 첫 Vertical Slice에서 지부가 단순 배경처럼 느껴지면 시각적 손상·NPC/유품·Workbench·전선 상태 등 **플레이에 필요한 최소 환경 서사**를 강화한다.
- 반대로 지부 관리가 백팩/전투보다 더 많은 조작과 설명을 요구하면 기지 시스템을 축소하고 지부를 서사·시각 중심 거점으로 유지한다.
- 장기 콘텐츠 확장 시 다른 지부/권역을 추가할 수 있지만, 첫 제품 정체성은 `무너진 지부에서 버티며 전설이 되어 간다`를 보호한다.
