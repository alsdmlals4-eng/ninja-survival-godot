## DEC-2026-08-20-003 · 난세를 평정하는 「닌자의 신」 전설

상태: `APPROVED_BY_USER_2026-08-20`

### 승인된 핵심

- 옛 전설에는 **천하가 난세에 빠질 때 「닌자의 신」이 나타나 혼란을 평정한다**는 이야기가 전해진다.
- 「닌자의 신」은 처음부터 플레이어에게 주어진 공식 직위나 예정된 혈통이 아니다.
- 플레이어는 네 유파 중 하나의 평범하거나 아직 미완성인 닌자로 현재의 난세를 살아간다.
- 전투·인법·도구·백팩 배치·조합·운명 선택을 통해 자기만의 닌자 방식을 완성하고, 실제 업적이 쌓인 끝에 **후대가 전설의 재림 또는 새로운 「닌자의 신」이라 부를 만한 존재**가 되어 간다.
- 핵심 감정은 `선택받았다 → 증명한다`가 아니라 **`살아남는다 → 강해진다 → 자기 방식을 만든다 → 난세를 평정한다 → 전설이 된다`**다.

### 기존 승인 요소와의 연결

- 4유파: 닌자의 신이 되는 하나의 정답이 아니라 서로 다른 닌자 철학/전투 방식.
- 백팩·조합: 플레이어가 자기 방식의 인법과 도구 체계를 실제로 구성하는 핵심 선택면.
- 운명: 난세에서 어떤 대가와 길을 받아들였는지 누적되는 Run 규칙/서사 선택.
- 닌자소울: 장기 진행과 전설 축적을 연결할 후보이며 정확한 서사적 의미는 후속 Decision에서 확정.
- 최종 결과: 이번 Run에서 어떤 닌자가 되었는지와 전설에 얼마나 가까워졌는지를 기억시키는 결과면.

### 보호 대상

- 기존 MVP-0~3 integrated runtime은 이 결정으로 변경하지 않는다.
- 승인된 MVP-4 `6x6 / 4x3`, Persistent Workbench, 공간 인접·회전·조합 결정은 유지한다.
- 네 유파의 기존 전투 감정과 대표 메커니즘을 삭제하거나 하나의 정답 유파로 수렴시키지 않는다.

### 명시적 비채택

- 태어날 때부터 선택된 구원자/예언된 혈통을 기본 코어로 두지 않는다.
- 네 유파가 단순히 공식 신좌 경쟁 시험을 개최한다는 구조를 기본 코어로 두지 않는다.
- 「닌자의 신」을 처음부터 고정된 최종 악역 한 명의 이름으로 한정하지 않는다.

### 벤치마크 원리 수준 참고

- `SHINOBI: Art of Vengeance`: 닌자 판타지의 행동 동기와 현재 위협을 빠르게 이해시키는 명료성은 참고하되 복수 서사를 복사하지 않는다.
- `Hades`: 반복 성공/실패를 세계와 이야기의 진행으로 연결하는 원리는 참고하되 그리스 신화·가족 서사를 복사하지 않는다.
- 닌자 서바이벌의 변형점은 **플레이 결과가 후대의 전설을 만든다**는 구조다.

## DEC-2026-08-20-004 · 인간의 전란이 요괴의 난을 불러온 복합 난세

상태: `APPROVED_BY_USER_2026-08-20`

### 승인된 핵심

- 과거 「닌자의 신」이 난세를 평정한 뒤 오랫동안 인간 세계와 요괴/이계의 경계는 안정되어 있었다.
- 시간이 흐르며 군벌·닌자 세력·권력자들이 다시 천하의 주도권을 놓고 전쟁하기 시작했다.
- 전쟁이 길어지자 일부 세력은 승리를 위해 **금지된 인법·주술·봉인된 힘**까지 사용했다.
- 반복된 전쟁·죽음·금기의 남용으로 봉인과 영적 경계가 약해지고, 요괴·원혼·잠식이 인간 세계로 퍼졌다.
- 현재의 난세는 인간 전쟁과 초자연 재앙이 서로를 키우는 악순환이다.

```text
인간의 전란
→ 금기의 힘 남용
→ 봉인·영적 경계 붕괴
→ 요괴·원혼·잠식 확산
→ 인간 세력의 추가 무장·금기 사용
→ 더 큰 전란
```

### 플레이/콘텐츠 연결

- 인간계 적: 적대 닌자, 군벌 병사, 용병, 금지 인법 사용자, 잠식된 닌자.
- 초자연 적: 요괴, 원혼, 이계 존재, 난세에서 증폭된 재앙성 존재.
- 복합 보스: 금지 인법과 요괴 힘을 결합한 인간, 인간의 전쟁 때문에 태어나거나 강화된 대요괴 등.
- 지역별로 `누가 무엇을 위해 금기를 썼는가 → 어떤 봉인/경계가 무너졌는가 → 어떤 재앙이 나타났는가`를 변주해 콘텐츠를 확장할 수 있다.

### 장기 방향

- 모든 문제를 한 명의 흑막 탓으로 축소하지 않는다. 개인 악역은 존재할 수 있지만 **난세 자체는 인간의 욕망·전쟁과 초자연 재앙이 연결된 구조적 문제**다.
- 따라서 플레이어의 최종 성장은 단순 최종보스 처치만이 아니라, 악순환을 끊고 천하를 다시 안정시키는 방향과 연결한다.
- 네 유파는 이 재앙에 대응하는 서로 다른 닌자 철학/기술 전통으로 유지한다.

### 보호/비채택

- 기존 적 설정의 `잠식 닌자 + 요괴`를 자연스럽게 보존한다.
- 요괴가 이유 없이 갑자기 나타난 단순 봉인 붕괴만을 코어 원인으로 두지 않는다.
- 네 유파 전체를 난세의 직접 원흉으로 만들지 않는다.
- 특정 유파 하나를 기본 악역 유파로 고정하지 않는다.

### 벤치마크 원리 수준 참고

- `Nioh 2` 등 전란과 초자연 위협이 공존하는 작품에서 **인간 갈등과 요괴 위협을 같은 세계의 문제로 읽히게 만드는 원리**만 참고한다.
- 역사 인물·실제 사건·요괴 설정·서사 구조는 복제하지 않는다.
- 닌자의 신의 차별점은 **금기의 힘이 전쟁을 이기기 위한 도구로 쓰일수록 난세 자체가 더 강해지는 악순환**이다.

## DEC-2026-08-20-005 · 한 Run = 4개 난세 권역 평정 원정

상태: `APPROVED_BY_USER_2026-08-20`

### 승인된 핵심

- 한 Run은 기본적으로 **약 20분 동안 4개 난세 권역을 차례로 돌파·평정하는 원정**이다.
- 기존 `약 3분 엘리트 → 약 5분 세그먼트 보스 → RESULT → 보상/Workbench/Fate` 구조를 한 권역의 대표 리듬으로 세계관화한다.
- MVP/Vertical Slice 단계에서는 **고정 4권역**으로 제작량과 검증 변수를 통제한다.
- 장기적으로 충분한 지역 콘텐츠가 쌓인 뒤에만 여러 권역 중 일부를 고르는 **선택형 평정 경로**를 재검토한다.

```text
유파 선택
→ 제1 권역 0~5분
   전투 → 약 3분 엘리트 → 약 5분 권역 보스
→ RESULT → 보스 보상 → Workbench → Fate
→ 제2 권역 5~10분
→ RESULT → 보스 보상 → Workbench → Fate
→ 제3 권역 10~15분
→ RESULT → 보스 보상 → Workbench → Fate
→ 제4 권역 15~20분
   최종 전선 → 최종 보스
→ 최종 결과 → 전설/닌자소울
```

### 권역의 역할

- 각 권역은 난세의 서로 다른 원인·상처·재앙을 보여주는 **독립적인 전투 문제 + 세계관 증거**다.
- 권역 예시는 `군벌의 금지 인법 전선`, `대량 죽음으로 원혼이 들끓는 폐허`, `봉인 붕괴로 요괴가 점령한 지역`, `인간과 요괴의 힘이 뒤섞인 성채`처럼 구성할 수 있으나 정확한 4권역 정본은 후속 Decision에서 확정한다.
- 개인 악역·군벌·닌자 조직은 특정 권역의 주요 적대세력이 될 수 있지만, 난세 전체를 한 악당 제거 문제로 축소하지 않는다.

### 플레이어 경험 연결

- 각 5분 권역은 `새 문제 인지 → 전투 적응 → 엘리트로 빌드 점검 → 보스로 권역 결산 → 결과/Workbench에서 다음 권역 준비`의 반복 구조를 가진다.
- 플레이어는 단순히 시간을 버티는 것이 아니라 **난세의 상처를 하나씩 평정하며 전진한다**고 느껴야 한다.
- 4번째 권역과 최종 결과에서는 이번 Run의 선택·유파·빌드·운명이 어떤 닌자를 만들었는지 회수한다.

### 제작 범위/장기 적합성

- MVP에서는 랜덤 월드맵, 다중 분기 노드, 세력 판도 시뮬레이션을 추가하지 않는다.
- 고정 4권역으로 아트·적·보스·UI·사운드·난이도 곡선의 품질을 먼저 검증한다.
- 출시 후보 이후 콘텐츠 풀이 충분할 때 `선택형 권역 경로`를 재검토한다.
- 재검토 신호: 고정 4권역이 반복 플레이에서 지나치게 동일하게 느껴지거나, 최소 6~8개 이상 완성도 높은 권역 후보가 확보된 경우.

### 보호/비채택

- 기존 MVP-0~3 구현과 승인된 MVP-4 Workbench/백팩 구조를 유지한다.
- 중앙 악역 하나를 추적하는 선형 복수극을 기본 Run 구조로 채택하지 않는다.
- 초기부터 세력 동맹·영토 판도·정치 시뮬레이션을 코어 시스템으로 추가하지 않는다.

### 벤치마크 원리 수준 참고

- `Hades` 계열의 구간별 전진·보스 종점·Run 반복성에서 **전진하는 감각과 구간 결산 원리**만 참고한다.
- `Nioh 2` 등에서 **전란과 초자연 위협을 지역별 환경·적·보스로 변주하는 원리**만 참고한다.
- 닌자의 신의 변형점은 각 권역이 단순 biome가 아니라 **난세의 서로 다른 상처를 평정하는 과정**이라는 점이다.
