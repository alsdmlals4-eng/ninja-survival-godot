# 전투 테스트 제어 사용 기록

GitHub Issue #96의 전투 테스트 제어는 천술류의 실제 세로 슬라이스를 빠르게 관찰하기 위한 로컬 런타임 보조 기능이다.

## 사용법

- 유파를 선택한 뒤 `궁극기 [Enter]` 버튼 또는 `Enter` 키로 준비된 궁극기를 사용한다. 천술류의 Trace 회수는 별도 `흔적 회수 [R]` 버튼 또는 `R` 키를 사용한다.
- HUD의 안내문은 자동 투사체의 대상 선택과 현재 유파 궁극기의 실제 효과를 함께 설명한다.
- 천술류 전투 중 `TEST · 정예 소환`은 확대된 정예 테스트 대상을, `TEST · 중간 보스 소환`은 Tier 2 보스 테스트 대상을 추가한다.
- 유파 선택 화면에는 유파별 도움말 버튼을 두지 않는다. 전투 중 현재 유파 도움말은 유지한다.

## 보호 경계

- TEST 대상은 Route, Trace, Boss gate, Workbench, 보상 선택, Fate, GOLD, Reward Orb를 진행하거나 지급하지 않는다.
- TEST 중간 보스는 실제 보스 정리 시 함께 제거되어 Workbench 뒤에 남지 않는다.
- TEST 대상 처치는 현재 전투의 즉각적인 유파 자원/전투 반응만 관찰할 수 있게 하며, 정식 세로 슬라이스의 Human QA 결과를 자동으로 통과시키지 않는다.
- 이 기능은 플레이어용 진행 단축이나 정식 밸런스 변경이 아니다.
