## 최신 승인·수정: 시작 인법과 장비도 가방 점유

사용자가 직전 권장 방향에 동의하고 시작 인법/장비도 가방을 차지한다고 명시했다. 아래 초기 제안의 ‘내장2’와 가방을 쓰지 않는 시작 장비는 폐기한다. 태그·시작3택1×2·24인술/8무기·흡수/강화의 권장 방향은 기획에 채택한다. 수치/전체 기술 명세 완성과 게임용 아트 최종 LOCK은 별도다.

시작은 **일본도 + 수리검 + 선택한 인법서2개**를 실제 아이템으로 지급하고 가방에 배치한다. 획득만 하거나 준비 버퍼에 둔 물건은 자동공격·인술·장착 보너스를 주지 않는다. 가방에서 빼면 해당 능력도 확정된 빌드에서 빠진다. 전투 중 가방을 실시간으로 고치는 기능은 추가하지 않는다. 시작 인법이 가방 밖에서 계속 발동하는 숨은 내장 슬롯은 없다.

초기 배치 권장안은 기존 무기 기하를 유지한다.

| 시작 내용물 | 크기 | 점유 |
|---|---|---|
| 일본도 | 1×3 | 3칸 |
| 수리검 | 1×1 | 1칸 |
| 인법서 A | 1×2 | 2칸 |
| 인법서 B | 1×2 | 2칸 |
| 합계 | 3×3 가방 안 | 8/9칸, 여유1칸 |

위에서 아래 순서: `도 A B` / `도 A B` / `도 수 빈`. 모든 시작 선택 대상 인법서는 동일1×2로 만들어 4유파의 어떤 두 인법 조합도 공간 때문에 시작 불가가 되지 않게 한다. 이는 초기 권장 규격이며 현재 추가 인법서 전부가 구현됐다는 뜻은 아니다. 지급·자동 기본배치·사용자 재배치·출전 확정 흐름으로 시작4개가 들어간 첫 빌드를 확인한다. 슬롯 제한은 가방 배치를 대체하지 않는다. 인법 최대4/타유파최대1의 초기안도 모두 가방을 점유하는 활성 인법 수로 해석한다.

비교: A 시작품 전부1×1은 여유가 많지만 장비 모양의 의미가 약해 보류. B 기존 일본도1×3/수리검1×1+책각1×2는 8칸으로 실제 포장 가능해 채택 권장. C 시작가방 확대는 사용자3×3 방향을 바꾸므로 기각. ‘더 작은 장비/인법으로 교체하여 다른 물건을 넣기’와 ‘가방 확장 구매’가 같은 공간 선택의 일부가 된다.

반드시 함께 바꿀 후속: 기본무기 내장 발동 제거, 비전과 실제 무기의 이중 지급 제거, 시작 인법2개 아이템 생성/초기배치, 인접·회전·버퍼 전투력0, 제거/교체 후 보너스 원복, 두 선택과 배치의 저장/복원, 첫 출전 유효성. 옛73쪽 PDF와 NS-DESIGN-RULES/구현 packet 본문은 아직 이 승인 변경 전 스냅샷이며 아래와 함께 재작성해야 한다.

근거: 현재 `scripts/data/mvp4_catalog.gd`에 일본도1×3/수리검1×1이 실제 존재한다. 책1×2는 이전 상세안과 일치한다. [Backpack Hero 공식 소개](https://store.steampowered.com/app/1970580/Backpack_Hero/)의 소지뿐 아니라 배치가 중요하다는 원리를 ADAPT하며 크기/턴제/콘텐츠를 복제하지 않는다. 외부 자료는 우리 배치 수치의 플레이 검증이 아니다.

이번 변경 검토는 기존 전체5회 계보의 후속 승인 교정이다. 새 전체 감사로 회차를 초기화하지 않는다. 8개 셀의 경계/중복과 유파별6종 중2종의60가지 시작 조합을 동일 규격으로 점검한다. 배치 가능성과 실제 게임 시작/모션/재미 검증은 분리한다.

## 이전 제안과 검토 이력 — 위 승인 사항이 우선

기존 73쪽 PDF는 이번 변경 전의 검토본으로 보존한다. 이 문서는 변경안과 충돌 검토를 소유하며, NS-DESIGN-RULES를 승인 없이 덮어쓰지 않는다. 기존 P01 입력은 아래 의미 변경이 정리된 뒤 다시 동기화해야 한다. 게임 구현·자산 LOCK·main 병합은 하지 않는다.

## 1. 태그 — 표시와 계산을 분리

| 주 태그 | 의미 | 적용 예 |
|---|---|---|
| 근접 | 본체 주변 무기 타격·근접 인술 피해 | 일본도, 쌍단도, 수라진 |
| 투사 | 날아가는 무기·인술의 해당 피해 성분 | 수리검, 쿠나이, 활, 부륜 |
| 인술 | 인법서에서 발생하는 효과 | 식신, 결계, 상태술, 인술 투사체 |
| 이동 | 이동속도·대시 충전 등 이동 지원 | 결계보법, 뇌보, 연막보법 |
| 생존 | 보호막·피해 감소 등 방어 지원 | 수호결계, 빙막, 철혈호체 |

세 대안: `원거리`는 익숙하지만 즉발 원거리 인술/긴 창과 거리를 혼동한다. `암기`는 닌자 분위기는 좋으나 활·인술 탄을 포함하기 어렵다. **`투사` ADAPT**는 범위가 명확하다. 최초 도움말에는 ‘수리검·화살처럼 날아가는 공격’으로 설명한다. `사격`은 던지는 무기를 포괄하지 못해 REJECT.

태그는 상호배타적 직업이 아니다. 카드에는 주 태그와 부 태그를 표시한다. 다만 피해 증가는 효과 성분별로 계산한다. 인술 투사체는 [인술][투사]일 수 있지만 생존/이동 태그는 피해 배율을 주지 않는다. 직접 생성한 장판에는 투사 피해를 자동 상속하지 않는다. 폭탄의 직접 타격/폭발은 각각 명시하고 같은 대상을 중복 타격하는지 공개한다.

같은 modifier ID는 같은 성분에 한 번만 적용한다. 서로 다른 ‘인술 피해 +10%’와 ‘투사 피해 +15%’는 해당 성분에서 합산해 +25%이지 1.10×1.15배가 아니다. 하나의 원천이 두 태그에 일치한다고 두 번 가산하지 않는다. 장비 툴팁에는 영향받는 현재 무기/인법 이름을 표시한다. ‘인술 피해’는 결계 지속/피해 감소를 강화하지 않으며 해당 능력의 전용 문구가 필요하다.

무기 카드 예: 일본도 — [근접], 자동 부채꼴 베기, 장착 중 근접 피해 증가. 수리검 — [투사], 자동 직선 투사, 장착 중 투사 피해 증가. 전역 범주 보너스와 무기 자신의 기본 피해는 별도 필드. 자기 무기도 범주 보너스를 한 번 받으며, 교체하면 이전 보너스는 사라진다. 기존 비전 아이템과 합칠지 여부는 무기 교체안 승인 후 단일 정의로 통합하고 이중 지급하지 않는다.

## 2. 시작 인법 3택1 × 2

권장 흐름: 시작 유파 선택 → 인법 선택 1/2 → 인법 선택 2/2 → 선택한 두 인법 확인 → 전장 선택 → 출전.

- 기존 고정 시작 인법 1개를 **선택한 인법 2개로 대체**한다. 고정 인법을 숨겨 추가하지 않는다. 시작 구성은 일본도+수리검+인법2개. 방어 인법을 고르면 네 가지가 모두 공격인 것은 아니다.
- 유파별 6개 중 중복 없는 첫 3개, 남은 3개를 두 번째로 제시한다. 첫 화면은 피해를 주는 인법 최소 2개를 포함한다. 선택 안 한 카드도 이후 정상 획득 가능하다.
- 한 런에서 동일 인법 중복 선택 금지. 뒤로 가기/저장 재개는 같은 카드와 선택 상태를 보존하며 재추첨하지 않는다. 둘 다 완료하기 전 전투는 시작하지 않는다. 새 유파로 변경하면 두 선택을 폐기한다는 확인을 보여준다.
- 두 시작 인법은 별도 내장 슬롯을 사용해 3×3 가방을 잠식하지 않는 안을 추천한다. 추가 인법은 기존 가방 배치와 확정이 필요하다.
- 추천 용량은 내장2+가방추가2=인법 최대4, 그중 타 유파 추가 인법 최대1을 우선 시험. 이전 ‘내장1+추가2’와 다른 제안이다. 슬롯 수 증가는 몹 수 제한과 무관하다.
- 유파 자원/오의는 시작 유파가 소유하며 특정 고정 인법을 골라야만 충전되는 설계를 피한다. 선택하지 않은 옛 starter가 몰래 공격하거나 자원을 생산하면 안 된다. 구체적 충전 사건은 선택 기술 조합별로 회귀 시험해야 한다.

세 대안: 고정1+선택강화2는 사용자 요청을 기술 선택이 아닌 강화 선택으로 바꿔 REJECT. 자유6택2는 이해가 쉽지만 무작위 선택 의미가 약해 REFERENCE_ONLY. 중복 없는 3택1 두 번을 ADAPT한다. 6종 전체를 두 묶음으로 보므로 희귀성보다 묶음별 선택 조합의 변화를 주는 설계이며, 더 큰 풀로 확장하기 전 반복감부터 시험한다.

## 3. 흔적 — 폭을 늘릴지 깊이를 늘릴지

권장하는 기본 분기는 사용자안과 같다. 시작 유파는 런 도중 바뀌지 않는다.

| 선택 | 얻는 것 | 얻지 못하는 것 |
|---|---|---|
| 유파 흡수 | 클리어한 타 유파 인술을 이번 런의 획득 후보에 추가 | 자동 장착·타 유파 오의·자원·즉시 전체 능력치 |
| 유파 강화 | 시작 유파의 숙련 1단계 | 이번에 넘긴 유파의 신규 획득 풀 |

**시점 변경은 필수 연동**: 군중→엘리트(상자)→시간/경고→보스→스테이지 클리어→안전한 결과/준비 화면에서 흔적 회수와 분기. 보스 등장 조건에서 흔적 회수를 제거해야 한다. 옛 ‘보스 전 흔적 접촉’과 새 ‘보스 후 흔적 선택’을 동시에 요구하지 않는다.

흡수는 미래 선택이고 강화는 즉시 효과라서 강화만 유리해질 수 있다. 권장 보완은 흡수 직후 준비 보상의 한 자리에 새로 연 유파의 합법 인법서를 **보장해서 제시**하는 것. 무료 지급이나 자동 장착은 아니며 기존 보상 선택권 1회를 사용한다. 보유/장착 불가능한 카드만 억지로 제시하지 않는다. 최종 준비에서도 같은 창에서 이용 가능해야 마지막 흡수에 의미가 있다.

강화 첫 시험안은 ‘시작 유파 인술 피해 +10%, 피해가 없는 인술의 지속시간 +10%’를 숙련마다 가산하고 최대4단계. 오의 피해·무적 시간·대시 충전·타 유파 인법에는 적용하지 않는다. 기존 피해 감소 상한을 올리지 않는다. 수치는 밸런스 확정이 아니며 기술별 이득 차이가 크면 유파별 숙련표로 바꾼다. 오의 변경까지 동시에 얹는 대안은 범위·가독성 비용으로 DEFER.

시작 유파 전장을 클리어하면 그 인술은 이미 열려 있어 ‘흡수’가 무효다. 이때는 **‘이미 전승한 유파’라고 설명하고 유파 강화만 제공**하는 예외를 추천한다. 자동 적용 전에 결과를 보여주고 확인받되 가짜 2택1을 만들지 않는다. 다른 세 유파 전장에서는 흡수/강화 둘 다 제공한다. 이는 별도 사용자 검토 항목이다. ‘인법 전수’로 왼쪽 이름만 바꾸고 기존 보상권을 소비하게 하는 대안은 오른쪽이 같은 보상에 강화까지 주어 우월해질 수 있어 기각했다.

선택은 해당 스테이지별 1회, 변경 불가 최종 확인 후 준비 거래와 함께 원자적으로 저장한다. 실패/중복 클릭/재개 시 해금과 강화가 둘 다 적용되면 안 된다. 열린 풀과 숙련 레벨은 별도 상태. 예전 저장은 자동 재해석하지 않는다.

대안 비교: A 사용자안의 순수 해금/강화는 가장 단순하나 늦은 흡수 가치가 낮다. B 해금+즉시 인법 무료 지급은 보상 경제를 바꿔 보류. **C 해금+현재 보상 안의 신규 인법 제시 보장**을 추천하며 보상권 중복 지급은 금지한다. 타 유파 슬롯1 때문에 세 유파 흡수는 ‘세 개 동시 장착’이 아니라 교체 선택지 증가임을 명시해야 한다.

## 4. 인술 확대 — 기존12 + 신규12 = 24 후보

기존12 ID는 보존한다. ‘인법서’는 얻는 물건, ‘인술’은 자동 실행 능력이라는 용어를 사용한다. 아래 신규12는 이름/역할/제약 제안이고 수치·모션/VFX·자원 사건까지 승인 완료된 구현 명세가 아니다.
